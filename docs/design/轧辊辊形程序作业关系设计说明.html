轧辊、辊形、程序与作业的关系

以轧辊为中心：每支辊一个唯一编号，台账带"这支辊正常怎么磨"的计划；辊形库、程序库与具体轧辊无关；作业是一页核对单——选辊、看一眼、✓ 下发。经设备厂商、车间管理者、操作工、工艺员、质检五个角色三轮评审（修正 23 处），第 2 版留下的 6 个待确认项已按调研结论定下（第 2 节）。

0结论

辊号是主线一支辊一张台账卡；作业、磨削记录都挂在辊号下。
台账带计划登记新辊必选目标辊形、磨削程序；另有"用途"字段便于批量改计划。
库与轧辊无关辊形、程序可复用；保存即生效、旧版本留档；改被引用的条目先看"在用清单"，可另存为新的；被引用的不能删只能停用。
作业一页待磨清单里点辊 → 核对页（计划、本次磨削量、核对结果、磨成什么样）→ ✓ 下发。
改了说清楚换辊形 / 程序：仅本次（常用原因一键选）或变更这支辊的工艺（写回、记改动）。
磨完有结论按辊形公差判合格；不合格一键返磨；记录存实际下发快照，台账自动更新。

2待确认项：调研与结论

#待确认项调研要点最优解（定稿）
1作业合成一页；本次磨削量为主输入轧辊车间按"这次磨掉多少"来下单（磨削量由磨损、缺陷深度决定），目标直径是结果；原机"工艺参数"屏也以"额定磨除"为参数采纳。一页核对；本次磨削量为主输入，目标直径算出并显示；"测量磨前直径"可实测替换
2库被引用时的改动规则配方（recipe）管理的通行做法：多个版本可以共存，但只有一个是"生效"的；改之前能看到"在哪里被用"（where-used）；改动可追溯、可回看。审批流在批量化工厂常见，单台磨床、管理员权限已足够时属于过度设计保存即生效 + 旧版本留档 + 在用清单 + 停用，不加审批流。保存被引用的条目时先列在用的辊，选"更新（下次起用新版本）"或"另存为新的"；每次保存版本号 +1，旧版本只读留档，快照记版本；被引用的不能删只能停用
3"用途"代替机架对照表轧辊管理系统按"机架 / 用途"分组管理辊子与凸度；单机场景下维护一张对照表收益小、出错面大采纳，并改为从已有值里选。用途在竖键里列出已有值（避免"F3上辊""F3 上辊"两种写法），可"新用途…"；批量改计划按用途筛选
4合格判定 + 返磨；中断续磨 / 结束车间工单以检测结果关闭（直径、凸度、粗糙度等）；急停后通行做法是回安全位置、重新测量再启动采纳。合格判定 = 辊形误差 ≤ 辊形公差，且圆度、锥度等 ≤ 标定里的验收公差（已有的 MachineCalibration 验收项）；不合格一键返磨。中断续磨必须先测量
5报废直径下发给 NC 做保护数控磨床控制里常设"最小直径"参数，由 NC 自己判断；符合"下发后上位机不参与控制回路"的最高原则采纳为可选。新增逻辑名 job.scrapDiameterMm；tagmap 登记了就随作业下发，由 NC 在磨前测量后判断、超限停机报警（需机床厂在 NC 程序里加判断，列为调试确认项）；未登记时只做上位机下发前核对，诊断里显示"NC 侧报废保护：未启用"
6台账导入导出的时机上线当天要把现有几十到上百支辊录进台账，逐支手录慢且易错；导出主要给报表和对接用，不急导入提前到第 1 期（附模板，逐行预览问题、整体导入）；导出留在第 5 期

调研来源：配方生命周期与版本管理（Automation World、SG Systems、AVEVA Recipe Management）；数控磨床最小直径参数（MachMotion 磨床编程手册）；轧辊车间工单与检测关闭（Oxmaint 轧辊管理）；急停后回零重启（USPTO 5315789 数控磨床控制）。公开资料有限，结论以通行做法为准，现场有特殊要求再调。

2′四样东西与关系

东西现实里是一句话谁维护
轧辊（台账）一根实物辊这根辊什么样、正常怎么磨、磨过几次、还能磨多少登记：班长 / 操作工；改计划：工艺员（或作业里"变更"）
辊形库设计图纸磨成什么形状、公差多少工艺员
程序库工艺卡用什么工序、进给、余量分配、倒角去磨；适用什么类型（材质）的辊工艺员
作业工单这一支辊这一次：按计划、磨多少、核对结果；下发时存快照操作工
辊形库 · 程序库→ 被台账引用为计划 →轧辊→ 每次磨削 →作业（快照）→磨削记录（合格 / 不合格）

方向只有一条：台账引用库，作业引用台账。程序不绑辊形，库不知道谁在用它（但能查出被谁引用，见 T1、T2）。

3每个数只有一个出处

数唯一出处说明
辊号、类型、材质、用途、状态（在用 / 作废）台账用途是自由文本（如"F3 上辊"），用于筛选与批量改
辊身长度、公称直径、报废直径、重量台账登记时按 machine.json 机床能力核对
当前直径台账，磨完 / 中断结束时自动写入实测作业磨前直径默认取它，可实测替换
目标辊形、磨削程序（计划）台账，登记必填只在"变更"、台账修改、批量改时改
形状、设计长度、公差、版本辊形库—
工序、进给、速度、道次、标准余量、余量分配、倒角、适用类型 / 材质、版本程序库—
磨前直径、本次磨削量（→ 目标直径）、程序步骤开关、例外类型与原因作业—
实际下发快照、磨削结果、合格判定磨削记录V3、Q1

4库与具体轧辊无关

库参数是否与具体辊无关做法
辊形直径、位置无关相对偏差（直径量 µm）；Z 从头架侧辊身端面量起
辊形长度（一般）无关两端锥度段绝对 mm，中间主段自动铺满
辊形长度（CVC、点表）例外保留设计长度；作业时差 ≤ 2% 中段伸缩，超出拦住
程序磨削量、进给、道次、砂轮与拖板速度无关粗磨按本次磨削量吸收差额，精工序不变
程序行程、倒角无关现有参数没有绝对 Z；行程默认整根辊身，倒角从两端量
程序工件转速 r/min例外作业时按直径核对线速度、按辊重核对转速上限（V1）
程序适用类型 / 材质例外类型不符拦住，材质不符提示（T5）

库的维护规则（T1、T2）

  • 保存即生效，版本号 +1；旧版本只读留档，可查看、可"以此为底另存为新的"，不能直接改回。
  • 保存一条被引用的辊形 / 程序：先列出"在用清单（N 支辊）"，选更新（这些辊之后新开的作业按新版本；已下发的不受影响）或另存为新的。作业快照记版本号。
  • 不设审批流：编辑库本身要管理员权限，改动记录记谁、何时、版本几到几。
  • 被引用的不能删除，只能停用：不再出现在登记和"更换…"列表里；停用前提示先把在用的辊改到别的。
  • 编辑时可挑参照辊预览、估时、校验；参照不存进库。

5操作流程

5.1 新辊登记（单支或导入）

  1. 入口：作业首页输入未登记的辊号 → "台账里没有这支辊，按 ✓ 新登记"；或台账 › "新登记轧辊"；或台账 › "导入"（表格批量，M3）。
  2. 必填：辊号（唯一、不可改）、类型、辊身长度、公称直径、目标辊形、磨削程序；选填：当前直径（缺省 = 公称）、报废直径（建议填）、材质、用途（竖键列已有值，可"新用途…"）、重量。竖键"照同类辊复制"带出计划与用途。
  3. 保存核对：辊号不重复；尺寸、重量不超机床能力（V2）；报废直径 < 公称直径；辊形长度匹配；程序类型匹配（材质不符提示）。导入时逐行预览问题，修正后整体导入。

5.2 日常磨削：一页核对

作业首页：待磨清单 + 辊号输入→核对页→✓ 下发
  1. 作业首页：上方辊号输入（尾号模糊匹配，扫码枪可用）；下方待磨清单（最近下线、中断待续、返磨待做的辊，按时间排）。点一支进核对页。
  2. 核对页（一页）：
    • 这支辊摘要：尺寸、当前 / 报废直径、剩余可磨量、上次磨削。
    • 计划两行：目标辊形、磨削程序；各带"更换…"（O5）。旧数据推断出的计划首次显示标黄"由历史推断，请确认"。
    • 本次磨削量（主输入，默认 = 程序标准余量）→ 系统算出预计目标直径；"测量磨前直径"键可实测替换磨前直径（O3）。
    • 第 6 节全部核对结果；"磨成什么样"曲线（含程序倒角，T4）。
  3. 全部通过，竖键 8"✓ 确认下发"亮；下发后转自动页，按钮板循环启动。

正常情况：点辊 → ✓ 下发。

5.3 换辊形或程序：仅本次 / 变更

按"更换…"选了不同的辊形 / 程序，确认时：竖键列出 仅本次 与 变更这支辊的工艺。选仅本次时竖键再列原因常用项：试磨 · 临时调机架 · 设备原因 · 返磨 · 其他（只有"其他"需输入）（O2）。

"变更"的权限由 hmi.json 开关决定，默认操作者可（M2）。

5.4 工艺员改计划（含批量）

  • 台账里改单支辊计划；或按用途（已有值列表）筛选、多选 → "批量改辊形 / 程序" → 逐支核对，不符的列出不改 → 确认（T3）。每支各记改动记录。

5.5 中断（O4）

  • 作业状态：已下发 → 磨削中 → 完成 / 中断。急停、断电、手动结束等使作业停在"磨削中"未完成时，重启或下次进入作业首页，它出现在待磨清单顶部，标"中断"。
  • 继续本作业：先测量（提示），按剩余磨削量重算粗磨后重新下发，记录接在同一作业下。
  • 结束并记录：按最后一次测量值更新当前直径，记录标"中断"并写原因。

5.6 磨完之后（系统自动）

  1. 记录：12 项指标、曲线、实际下发快照（V3）、按计划 / 例外 / 变更标记；判合格 / 不合格：辊形误差 ≤ 辊形公差，且圆度、锥度等 ≤ 标定里的验收公差（Q1）。
  2. 台账：当前直径 = 磨后实测；次数 +1；累计去除量；剩余可磨量重算；履历加一行。
  3. 不合格：记录页与台账出现"返磨"，按同一计划新开作业，磨削量默认精磨量，原因"返磨"，进待磨清单。
  4. 剩余可磨量 < 2 次标准余量：台账、核对页提醒，进"临近报废清单"。

5.7 作废

有记录的辊不能删除只能作废；作废灰显、默认过滤，不能再下作业。未登记的辊不能下作业。
