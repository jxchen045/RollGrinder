轧辊、辊形、程序与作业的关系

以轧辊为中心：每支辊一个唯一编号，台账里带"这支辊正常怎么磨"的计划；辊形库、程序库与具体轧辊无关、可复用；作业只是把计划与这支辊的实际尺寸合起来，由系统算、由系统查，操作工扫码、核对、下发。

0结论

辊号是主线一支辊一个唯一编号、一张台账卡；每一次磨削的作业和记录都挂在辊号下面。
台账带计划登记新辊时必须选"目标辊形"和"磨削程序"，这就是这支辊的默认计划。
库与轧辊无关辊形库、程序库只放与具体辊无关的量，可反复用；与辊有关的数只在台账和作业里。
作业 = 确认扫辊号 → 计划和尺寸自动带出 → 系统计算并核对 → 看一眼 → ✓ 下发。正常情况零输入。
改了要说清作业里换辊形或程序，必须选"仅本次"（写原因，不改台账）或"变更这支辊的工艺"（写回台账、记改动记录）。
一份记录两个入口台账 › 磨削履历按辊看；"查询与报表"按时间、人、辊形、程序跨辊看。同一份数据。

1四样东西与关系

东西现实里是一句话谁维护怎么变
轧辊（台账）一根实物辊这根辊什么样、正常怎么磨、磨过几次登记：班长 / 操作工；改计划：工艺员（或作业里"变更"）每磨一次当前直径变小、履历加一行
辊形库设计图纸磨成什么形状工艺员基本不变；改了只影响以后的磨削
程序库工艺卡用什么工序、进给、余量分配去磨工艺员基本不变；改了只影响以后的磨削
作业工单这一支辊这一次怎么磨操作工一次性；下发时把辊形、程序各抄一份快照，磨完生成磨削记录
辊形库＋程序库→ 被台账引用为计划 →轧辊 R-2026-031→ 每次磨削 →作业（快照）→磨削记录（挂在辊号下）

关系只有一条方向：台账引用库（"这支辊用哪条辊形、哪支程序"），作业引用台账（"这一次按什么磨"）。库不知道哪支辊在用它，程序不绑辊形——三者互不嵌套，所以任何一个改了都不会把别的弄乱。

3库与具体轧辊无关

能把库与轧辊分开，前提是库里不放"某一支辊才有的数"。下表逐项说明；三处例外由系统在作业里自动核对，不靠人记。

3.1 辊形

参数与具体辊无关？做法
直径无关辊形是相对偏差（直径量 µm），基准是作业里这支辊的目标直径
位置无关Z 从"头架侧辊身端面"量起，相对辊身；辊身在机床上的位置由作业的启磨点决定
长度（一般辊形）无关两端锥度、倒角段用绝对 mm（对应板带边部，本不随辊变）；中间主段自动铺满剩余长度
长度（CVC、实测点表）例外 1按某个辊身长度整体设计，不能随意伸缩。保留"设计长度"；作业时辊身与设计长度差 ≤ 2% 中段自动伸缩，超出拦住

3.2 程序

参数与具体辊无关？说明
磨削量、连续 / 周期进给、道次、光磨、修整无关µm、mm/min 等量；粗磨按本次余量自动吸收差额（精工序不变）
砂轮线速度、拖板速度、换向停留、变速幅度 / 周期无关—
行程、倒角长度无关现有工序参数里没有绝对 Z 坐标：行程默认磨满整根辊身，倒角长度从辊身端部量起
工件（头架）转速 r/min例外 2（弱相关）保留 r/min（与原机一致）；作业时按这支辊直径换算线速度，超出允许范围拦住
适用辊类型例外 3程序标"工作辊 / 支承辊 / 通用"；登记与作业时类型不符拦住

3.3 与具体辊有关的数，只从这里来

辊身长度、当前 / 目标 / 报废直径、重量（台账）；启磨点（作业）。作业是唯一把"库里的相对量"和"这支辊的绝对量"合起来的地方，合完统一核对（第 5 节）。

3.4 编辑库时怎么看效果

辊形页、程序页仍可挑一支"参照辊"（或一组参照尺寸）用来预览曲线、估算时间、做校验；参照只在编辑时用，不存进库，也不是约束。

4操作流程

4.1 新辊登记（班长 / 操作工，约 1 分钟）

  1. 入口二选一：在作业里扫到台账没有的辊号 → 对话行"台账里没有这支辊，按 ✓ 新登记"（辊号已填）；或库 › 轧辊台账 › 竖键"新登记轧辊"。
  2. 填登记表：
    项必填说明
    辊号✓全厂唯一；登记后不能改
    类型✓工作辊 / 支承辊
    辊身长度、公称直径✓实物尺寸
    当前直径不填 = 公称直径；首次磨前测量后自动更新
    报废直径建议填；填了才有剩余可磨量与拦截
    材质、净重、轴承箱重吊装、托瓦用
    目标辊形✓列表只列长度相差 ≤ 2% 的（CVC / 点表按设计长度）
    磨削程序✓列表只列适用于该类型的
    竖键"照同类辊复制"：选一支已有的同类辊，一键带出它的目标辊形与磨削程序。
  3. 保存时核对：辊号不重复；报废直径 < 公称直径；辊形长度匹配；程序类型匹配。不过不让存，对话行说原因。
  4. 从作业进来的，按"« 返回"回作业，这支辊已选上。

4.2 日常磨削（操作工）

① 扫辊号→② 辊形和程序（带出台账计划）→③ 核对并下发
  1. 扫辊号：右侧显示这支辊摘要（辊身、公称 / 当前 / 报废直径、剩余可磨量、磨削次数、上次磨削）。台账没有 → 4.1。
  2. 辊形和程序：自动选中台账计划，画出辊形图。一般直接"下一步"。要换 → 4.3。
  3. 核对并下发：一页看完第 5 节全部核对项与"磨成什么样"曲线；全部通过竖键 8"✓ 确认下发"才亮；下发后转自动页，按钮板上循环启动。

最常见的情况：扫码 → 下一步 → 看一眼 → ✓ 下发。

4.3 作业里换辊形或程序：仅本次 / 变更

在第 2 步换了辊形或程序（或两样都换），按"下一步"时对话行确认（两样都换只问一次）：

对话行

辊形与台账不同：台账"工作辊-凸度300"，本次"工作辊-凸度200"。
竖键 6 仅本次 · 竖键 7 ✕ 取消（恢复台账的）· 竖键 8 变更这支辊的工艺

仅本次（默认高亮）变更这支辊的工艺
这次下发用改后的用改后的
台账计划不变下发成功后改成新的
原因必填（常用项：试磨 / 临时调机架 / 设备原因，或自填）不强制（改动记录里有前后对照）
核对页橙色"本次例外：凸度300 → 凸度200（试磨）""已变更：凸度300 → 凸度200"
磨削记录 / 履历标"本次例外"及原因标"变更工艺"
改动记录不记记：谁、何时、哪支辊、原值 → 新值
下次扫这支辊仍按原计划按新的

中途取消或下发失败，台账不动。操作工、班长、工艺员都能选两种（权限按建议，见第 7 节）。

4.4 工艺员改计划（含批量）

  • 换机架、换轧制计划时，在台账里改某支辊的目标辊形 / 磨削程序，效果等同作业里的"变更"。
  • 批量：台账多选若干支辊 → 竖键"批量改辊形 / 程序" → 选新值 → 逐支核对（长度、类型），不符的列出来不改 → 确认。每支辊各记一条改动记录。

4.5 磨完之后（系统自动）

  1. 台账：当前直径 = 磨后实测；磨削次数 +1；累计去除量增加；剩余可磨量重算；履历加一行。辊形、程序只在"变更"时才改。
  2. 磨削记录：12 项指标、4 条曲线、辊形与程序快照、按计划 / 例外 / 变更标记与原因。库以后改了，记录不变。
  3. 勾了"打印磨后数据"时自动打印。
  4. 当前直径接近报废直径（剩余不够一次标准余量）时，台账与作业页提醒。

4.6 作废

  • 辊号写错、辊子报废：标"作废"。有磨削记录的辊不能删除，只能作废。
  • 作废的辊在台账里灰着显示、默认过滤，勾"显示已作废"可看；不能再下作业。
  • 没登记的辊不能下作业（取消现在"下发时自动建一个空档案"的做法）。

5作业核对清单（系统算、系统查）

项系统怎么定不合格
磨前直径默认 = 台账当前直径；可按"测量磨前直径"实测。当前直径仍是公称值（新辊）时提醒"建议先测量"—
目标直径默认 = 磨前直径 − 程序标准余量；可改低于报废直径：拦住
本次余量= 磨前 − 目标；与标准余量不同时差额加减在粗磨上（多道粗磨按原比例），精工序不变少于精工序之和、或程序没有粗磨而余量不同：拦住
辊形长度辊身 = 设计长度 → ✓；差 ≤ 2% → 中段自动伸缩，写"中段由 ×× 调为 ××"差 > 2%：拦住，说明"辊形按 ×× mm 设计"
程序类型程序适用类型 = 辊类型，或"通用"不符：拦住
工件转速按目标直径把 r/min 换算成线速度超出机床允许范围：拦住
行程整根辊身（倒角从两端量），换算成机床 Z超出机床行程：拦住
程序步骤开关照程序默认，本次可改—
与计划的差异按 4.3 标"本次例外 / 已变更""仅本次"没写原因：不能下发
磨成什么样目标辊形套在辊身上，叠磨前实测线（辊形图统一规范：X 全辊身、Y 由目标辊形定、绘图区 4 : 1）—

2% 做成配置项（machine.json），默认 2%。

6台账与磨削记录

  • 数据一份：每条磨削记录带辊号、作业号，挂在辊号下。
  • 入口一：台账 › 这支辊 › 磨削履历（操作工、班长）：从进厂到现在每一次（日期、辊形、程序、磨前 / 磨后直径、去除量、按计划 / 例外 / 变更）；点一行就地展开 12 项指标与曲线，可打印。卡片上方显示累计磨削次数、累计去除量、剩余可磨量。
  • 入口二：记录区改名"查询与报表"（质检、管理）：按日期、班次、操作人、辊形、程序、例外与否跨辊筛选；日报、月报、磨前报表。点一行打开同一条记录。
  • 两个入口共用同一个"单条记录"视图。

10已定决策台账

#问题决定
1程序与辊形的关系互相独立；不绑定（撤销上一轮的"关联辊形"）
2管理主线以轧辊为中心，辊号唯一

6"仅本次"要原因吗必须（常用项可选）
