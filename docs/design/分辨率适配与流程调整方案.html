分辨率适配、辊形图统一与工艺流程调整方案

针对实机部署的两块屏（15″ IPC477E 1366×768、19″ IFP1900 1920×1080）重做版面规格；统一所有页面上辊形曲线的画法，保证同一条辊形在哪里看都是一个样；把"先选辊形、再编程序"做进工艺流程，并理清长度、直径、余量等参数该在哪里设。

0结论

两档固定画布1920×1080 标准档、1366×768 紧凑档各有一套尺寸与字号；在两块真实屏上都是 1:1，不缩放。其他分辨率取最近的一档整体等比缩放兜底。
字号按真屏重算原稿按 24″ 算字号；19″ 的像素小 21%，正文只有 14′，不达标。标准档正文 19→22 px，紧凑档 20 px。
紧凑档重排而不是压扁工作区最多两栏；第三栏挪进状态带、子视图或竖键；表格按优先级收列；数值不许截断。
辊形图一个规范X 永远是整根辊身，Y 按目标辊形取整，绘图区固定 4 : 1。辊形页、库、作业、自动、记录的同一条辊形形状完全一致。
程序先选辊形新建程序第一步选"关联辊形"；程序页顶上常驻这条辊形；行程、余量、估时都按它算，不再手填"参考辊"。
参数各归其主台账管这支辊（长度、直径、报废直径、重量）；辊形管形状与公差；程序管余量怎么分、怎么进给；作业管"这一次"（磨前、目标直径、本次余量）。

3分辨率适配方案

3.1 三种做法比较

做法好处问题结论
A 整体等比缩放（原稿写的）一套版面，改动最小1366 上缩到 71%：正文 13.5 px（10′）、软键 60 px 宽的字挤成一团，15″ 上看不清也点不准否决
B 完全流式自适应任意分辨率都能排每页要在连续尺寸下都不出错，测不完；现场只有两种屏，花大力气解决不存在的问题不采用
C 两档固定画布 + 兜底缩放两块真屏都是 1:1 清晰；每档的版面是确定的，可以逐页截图验收；第三种屏也不会乱紧凑档的几页要单独排（第 3.5 节列全了）采用

3.2 档位怎么选

  • 自动判定：启动时按主屏工作区（DIP）选档：宽 ≥ 1800 且高 ≥ 1000 → 标准档；否则 → 紧凑档。拔插显示器、改分辨率时重新判定并重排。
  • 手动锁定：hmi.json 加 "layout": "auto" | "standard" | "compact"，现场可以锁死，避免 Windows 缩放设置被人改了之后跳档。
  • 兜底缩放：整个外壳放在所选档的固定画布里（1920×1080 或 1366×768）。实际尺寸不同就整体等比缩放、留边居中，不会重叠。两块目标屏上缩放系数正好是 1。
  • 系统设置要求：两台机器的 Windows 显示缩放都设 100%，上位机全屏、隐藏任务栏（kiosk）。写进安装说明，诊断 › 系统里显示当前档位、缩放系数和 DPI。

3.4 版面规则（开发必须遵守，自检逐条查）

  1. 不写死宽高。页面里不出现 ≥ 200 的固定 Width / Height。栏宽用比例（*）加最小宽，最小宽取令牌（Layout.PanelMin 等），两档各一套。
  2. 所有尺寸、字号走令牌。Layout.Standard.xaml / Layout.Compact.xaml 两份资源字典，启动时按档位装入；页面只引用键名。
  3. 紧凑档工作区最多两栏。第三栏的内容按第 3.5 节挪到状态带、子视图或竖键，不硬挤。
  4. 曲线拿最大的一块，并按第 4 节画。曲线区给最小高度，不够就让表格滚动，不压曲线。
  5. 表格按优先级收列。每列标优先级 1–3，紧凑档隐藏 3 级列；选中行的全部字段在详情区看得到。
  6. 数值不截断。标签可以换两行；数值和单位放不下是版面错误，自检报错。
  7. 只在列表内滚动。整页不出现滚动条；滚动区域有可见的滚动提示。
  8. 触摸尺寸不低于第 2 节表格。

4辊形图统一规范

辊身 1800 mm、凸度 0.3 mm，真实比例画出来就是一条直线，所以辊形图一定是纵向放大的。放大多少，必须每一页都一样，否则同一条辊形在辊形页是"缓坡"，在作业核对里是"尖峰"，操作者会怀疑是不是选错了辊形。

同一条辊形（工作辊-凸度300），三个不同大小的容器
项规则
适用凡是画"辊形形状"的图：辊形预览、库预览、作业核对、新建程序选辊形、程序页关联辊形条、自动页"参考曲线"、记录"磨前 / 磨后"。所有页面用同一个控件（RollProfileChart），不各自拼。
X 轴永远是整根辊身 0 … L（Z 自头架侧辊身端面起，向尾架为正），不按数据缩放。刻度：两端、中点、段界（虚线）。
Y 轴直径量 µm。范围由目标辊形定：取最低点、最高点，外扩 25%，再按 1-2-5 取整；最小跨度 100 µm。同一条辊形在任何页面 Y 范围相同。实测线、磨前线超出范围时画到边上并标"↑ 超出"，不重新缩放。
绘图区纵横比固定 4 : 1（宽 : 高，不含坐标轴）。容器比例不同时绘图区居中、四周留白，不拉伸。于是"纵向放大倍数 = L ÷ 4 ÷ Y 跨度"只和辊形有关，和页面无关，图右上角写出来（如"纵向放大 ×900"）。
最小尺寸绘图区宽 ≥ 480 px（标准档）/ 400 px（紧凑档）；缩略图（列表行里）宽 160 × 高 40，只画曲线不画刻度。
线型与颜色目标 3 px 深蓝实线；实测 / 磨前 2 px 灰虚线；超差段 5 px；段界灰虚竖线；当前段红色半透明宽线。颜色取调色板色位，各页同一种线同一种颜色。
交互双指缩放、单指拖动；图角"⟲ 复位视图"回到上面的规范范围（不是回到自动缩放）。缩略图不响应手势。
偏差类图（误差、圆度、偏心、电流）不是形状图，用"偏差图"规范：X 同上（整根辊身）；Y 以 0 为中心对称，范围 = max(公差 × 2, 数据) 取整；有公差带。绘图区同样固定 4 : 1，自动页五条曲线切换时框不跳。

5轧辊参数归属：长度、直径、余量等在哪里设

判断标准只有一条：这个数跟着谁变。跟着这支辊一辈子变的归台账；跟着"要磨成什么形状"变的归辊形；跟着"用什么工艺磨"变的归程序；只对这一次有效的归作业；跟着机床和砂轮变的归参数。

6流程：先选辊形，再编程序

评估结论：你说得对。磨什么形状决定了怎么磨：凸度越大，粗磨余量越要保证能把凸度磨出来；辊身长度决定行程和估时；公差决定精磨道次。把程序做成与辊形无关的模板，是把这些检查都推迟到了作业下发前，编程序的人反而看不到。改为程序绑定一条关联辊形，同时保留"一支程序给同类辊形复用"的能力。
① 台账登记这支辊→② 辊形库：编 / 选辊形→③ 工艺程序：先选关联辊形，再编工序→④ 作业：选辊 → 推荐辊形 → 推荐程序 → 本次余量 → 核对下发

6.1 规则

  • 新建程序先选辊形："新建程序…"打开两步：① 选关联辊形（列表 + 大预览）② 程序名、起步方式（空白 / 复制现有程序 / 按默认值）、标准余量。
  • 程序页顶上常驻关联辊形条：缩略图 + 名称、辊身、公称直径、凸度、标准余量、余量分配是否对得上。点它打开辊形（只看）。
  • 按辊形校验：行程起止不超出辊身；粗磨余量 ≥ 凸度高差（从旧辊形改磨新辊形时）；估时按辊形的设计长度和适用直径算，不再手填"参考辊"。
  • 换关联辊形：横键"换关联辊形…"，换后重新校验，差异在对话行列出；已存的作业不受影响（作业存的是快照）。
  • 复用：作业 ③ 里程序按"关联到本辊形的"排在前面；选一支关联到别的辊形、但设计长度相同的程序，允许，黄色提示"本程序按 ×× 编制"；设计长度不同则不允许。
  • 旧数据：已有程序没有关联辊形，打开时提示"先选关联辊形"，选定并保存一次即可；不选也能看，但"用于作业"灰掉并说明原因。

7验收与自检（防止再出现"实机和设计稿不一样"）

  1. 版面自检（--selftest 新增 Layout 组）：按两档画布各跑一遍，逐页、逐横键功能组、逐子视图打开，遍历可视树检查：
    • 同一面板内的兄弟元素包围盒不重叠（浮层、弹框除外）；
    • 文字控件实际宽度小于需要宽度（被截断）→ 数值报错、标签报警告；
    • 元素超出窗口或被父容器裁掉；
    • 按钮、列表行的物理尺寸低于第 2 节；
    • 辊形图绘图区纵横比 = 4 : 1 ± 1%，同一条辊形各页的 Y 范围相同。
  2. 截图矩阵：每页 × 每组 × 两档存截图到 data/selftest/layout/，生成一页对照 HTML，交付时随包给出。
  3. 源码检查（单元测试）：扫 Views/*.xaml，页面里出现 ≥ 200 的固定 Width / Height、写死字号，测试失败。
  4. 实机验收：两台机器各按《操作测试手册》走一遍 A–L 场景，重点看 15″ 上的自动页、记录页、库、诊断。
