# 第 1 轮评审（工艺员 P、操作工 O）——要点存档
P1 辊形页中心为 0（−900…+900，中心竖线），顶栏：名义长度（取自台账）、实测长度、头/尾端非工作区、公差；非工作区阴影 高
P2 辊形、工艺两页共用一份草稿、一个保存，冻结方案改两处只出一个新号；路径条"方案 3 → 草稿（将存为方案 5）" 高
P3 打开冻结方案即黄条"已用 4 次·冻结，修改将另存"；保存键名"另存为新方案…" 高
P4 另存为新方案：新方案名、用途标签、"设为当前"勾选（默认勾）、新旧叠图带公差带 高
P5 工艺参数表列：参数、标准值、单位、可调方式（±%/只减/只加/不可调）、下限、上限（绝对值）、范围来源、机床硬限；折返时间、光磨单列 高
P6 全部方案列：★、方案号、名称、用途、状态（草稿/冻结）、来源、一致/已改动、辊形摘要、名义长度、使用次数、最近使用、建立人；竖键 设为当前…、复制为新方案、对比、删除（仅未用） 高
P7 必须采用逐支：辊号、机架、当前方案、一致/已改动、改动摘要、位置（在机/待磨/库存）、决定（默认普通提示）；竖键"一致的全部强制" 高
P8 存为新方案：逐项勾选调整，显示方案值/本次值/新值；所用方案已非当前时橙字提醒 高
P9 复制对齐一行：源/目标名义长度、差值、每端截/延 mm、非工作区宽度、判定；解析段段表前后对照 中
P10 复制范围：全部/仅辊形/仅工艺 中
P11 模板库列：名、机架、辊形摘要、更新日期、改动说明、复制自它的辊数（一致/已改动）、必须采用、采用进度 中
P12 台账左表加"当前方案"列；右侧当前+最近 2 个，标"标准已更新"，竖键"全部方案 ▸"；改用途时提示改用标签相符方案 中
P13 记录列：方案号、调整数、长度对齐、道次表（⚠缺）；筛选按方案号、只看有调整 中
P14 下发参数三列：方案值、本次值、调整人；对齐行、下发序号、NC 确认时刻；点列中心坐标 中
P15 道次表加"设定折返 Z"列与偏差；每工序倍率摘要和有效值 中
P16 总览加"同一参数连续调整 3 次的辊"→存为新方案 中
P17 模板不占左栏，放方案区横键"模板库"，编辑复用辊形/工艺页，路径条"模板 › …" 中
P18 调试：复制门槛 1 mm、下发容差（mm 和 %）、端部非工作区默认；"方案编辑权限"；默认范围按可调方式填 中
P19 从模板建方案（多支）："设为当前 / 只建立" 低
P 坚持：中心为 0 + 长度/非工作区/公差；一次保存成一个新方案、打开即提示冻结、设为当前由工艺员定；范围绝对上下限 + 来源 + 硬限，记录按方案号与调整追溯，存为新方案逐项选

O1 核对页提示一次只问一件，放对话行黄底竖键 6/7/8：先标准更新，再上次调整；长度对齐容差内只一行灰字；未答完确认下发灰 高
O2 上次调整写全"09-28 李工：拖板 800→720，光磨 2→3"；竖键 8 不沿用（稳妥），6 全部沿用…；单项进本次调整 高
O3 标准更新：普通更新只提示 + 新旧叠图，竖键 8 继续用原方案、6 改用新标准…；强制只"知道了"+叠图 高
O4 方案行、路径条先写辊形名 + 工艺名（L2），方案号小字后置；不显示版本号 高
O5 操作工不显示冻结、来源、已改动；"方案值/本次值"→"设定/本次"；作业里"当前方案"叫"这支辊的磨法" 高
O6 核对页竖键：1 换方案…、2 本次调整…、3 测量磨前直径、4 按最大可磨量、7 取消、8 确认下发 高
O7 磨削起点 Z 默认上次/方案值，改时才点；磨削量仍主输入 高
O8 运行中改参数不另开页：在参数矩阵里改，格子"800→600 等待 → 第 5 道起生效"；等待中灰键说明；"放弃改动"生效前可用 中
O9 参数矩阵不加列：改过的写"800→720"（标记底色），锁图标 中
O10 本次调整：范围写绝对值（720–880、≤2.0）；大号 +/− 步进键 ≥60 px 中
O11 长度超容差：红块写差多少；竖键 换方案… 或 中断处理（记"待工艺员"，辊回清单置顶） 中
O12 模板放方案区横键（仅管理员亮）；左栏第 4 格空着，砂轮仍 Ctrl+5 中
O13 方案区路径条辊号 L2；没选辊先选辊；操作者无权限整页只读 中
O14 道次数据缺失措辞"记录数据暂缺，机床照常磨"灰字；磨完只在缺时显示"记录缺第 x–y 道（不影响合格判定）" 中
O15 待磨清单右侧只放辊形名 + 工艺名 + 曲线 + 两个徽标（⚑ 上次有调整、⚑ 标准已更新） 中
O16 连续 2 次沿用同一调整 → 总览给工艺员"建议存为新方案" 低
O17 操作者台账只看当前 ★ 和最近 2 个；"设为当前…"灰键说明原因 低
O18 记录顶部五问折叠成一行 低
O 坚持：核对一次一问、竖键 8 永远按方案值；看辊形名与具体数不看方案号/冻结；标准更新现场不决定
