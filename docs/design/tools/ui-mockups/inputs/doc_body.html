5.2 规则（在 v3 第 5.2 节之上增改）

  • 上下文：方案区只编辑"显式打开的那支辊的那个方案"（从台账、核对、记录或方案列表进）；路径条写"方案 / 辊号 › 方案 n · ★ 当前 · 已用 n 次 · ● 未保存"，从别处跳入时右端写"« 返回 …"，返回后源页刷新。
  • 一次保存：辊形与工艺共用一份草稿；已用过的方案打开即显示信息条，保存进入页内决定（另存为新方案）。
  • 不阻塞的提示：核对页"本次注意"只陈述，默认取稳妥项；竖键 8 只给"确认下发"。
  • 改变以后怎么磨：设为当前、另存并设为当前、必须采用——只在竖键 6、带"…"、再问一次、可撤回；没权限时键灰并说明。
  • 选方案子视图一个：作业换方案、选原因、复制到本辊、多支从模板建方案共用；只换竖键 8 的字。
  • 坐标：全部辊形图、误差图、段表横轴为中心 0（头架 ← → 尾架）；下发点列仍按 NC 约定换算。
  • 就地改参数：自动页参数矩阵改动 → 写入 → ⧗ 等待生效 → 第 n 道起生效；生效前不收新的修改。
  • 术语：设定值 / 本次值；已用 n 次（不写"冻结"）；模板已更新；跨辊写"R-031 / 方案 3"。
  • 确认态互斥（R3-1）：对话行黄底等确认时，会提问的动作键和横键全部变灰，点了在对话行说"先 ✓ / ✕ 结束当前确认"；停止类键（砂轮停止、拖板停止、进给保持）与不需确认的键（冷却液）始终可按，按停止键即取消当前确认。页内决定里属于本次决定的竖键（如 5.6.2 逐支"这支：…"）照常可按。
  • 坐标系分工（R3-2）：中心 0 只用于辊形图、误差图和段表；示教、定位、位置窗、磨削起点 Z、测量对中一律用机床坐标。两者同时出现时，机床坐标为主，中心 0 小字换算（如"机床坐标 · 距辊身中心 −760"）。
  • 来源徽标（R3-2）：会被人当成"现在测的"的数要标来源：磨前直径［台账］/［实测］，磨削起点 Z［沿用上次］/［本次示教］。输入框里只放数字。
  • 磨前实测差（R3-2）：目标直径固定；磨前实测直径与台账不同，由粗磨吸收差值（现有 StockAdjustment）；实测余量低于精磨 + 光磨或超过最大可磨量时拦下。NC 自己的"磨前测量"步骤怎么处理差值，见《上位机与 NC 接口约定》第 9 节第 10 问。
  • 对话行长度（R3-8）：字号不降（仍是 22 / 20），两档各写一句，紧凑档写短句；生成器按估算宽度 × 1.08 检查，超出右侧 24 px 安全边距即告警。
