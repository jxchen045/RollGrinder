# 界面设计基准

本目录是界面的**唯一基准**。改界面之前先看这里，不要凭记忆改。

- `B-*.html` —— 六个页面的设计稿（方案B 浅色高对比，1920×1080 固定面板）
- `配色与字号规范.png` —— 三套配色（A 深色工业 / B 浅色高对比 / C 中性灰）与字号规范

三套配色共用同一套**语义色位**与尺寸规则，只换色值。当前实现按**方案B**落地，
色位以资源键的形式定义（`Themes/Palette.*.xaml`），换方案只需换一份色板文件。

## 字号与字体（1920×1080，观察距离约 0.6 m）

| 用途 | 字号 | 字重 | 字体 |
|---|---|---|---|
| 主测量值（实测直径） | 54 px | 600 | 等宽 |
| 参数值 | 30 px | 500 | 等宽 |
| 数据行 | 24 px | 400 | 等宽 |
| 正文与按钮 | 19 px | 400 | 中文 |
| 标签 | 15 px | 400 | 中文 |

字体：中文 **Noto Sans SC**，数字与位置值 **IBM Plex Mono**（等宽，跳动时不抖）。
**不使用 Inter、Roboto、Arial。** 工控机未装上述字体时回退到
`Microsoft YaHei UI`（中文）与 `Consolas`（等宽）——两者 Windows 自带，同样满足
"中文可读 + 数字等宽"。若要完全还原，把 OFL 授权的字体文件放进 `src/RollGrinder.App/Fonts/`
并改 `Typography.xaml` 的字体族即可。

## 版面规则

- 画布 1920×1080 固定；顶栏 76 px，底部功能条 86 px，中间区域 `padding 12`、卡片间距 `gap 12`
- 卡片：白底 + 1 px `#C5CAD2` 描边；卡片标题栏高 44 px，背景 `#F3F5F8`，文字 17 px `#4A5461`、字间距 1
- 参数网格：`gap: 1px` + 网格线底色 `#D8DDE4` 形成 1 px 分隔线（不是 border）
- 底部功能条：**8 个等宽功能键**，每页含义不同，最后一个恒为"返回"；
  主操作用实心强调色（启动为绿 `#1F7A4D`，保存为蓝 `#15507F`，危险为红 `#B3241C`）
- 顶栏：品牌 `RGX` + 页面上下文 + 报警/状态条（占满中间）+ 权限 + 时钟 `HH:mm:ss`

## 六个页面

| 页面 | 设计稿 | 结构要点 |
|---|---|---|
| 自动磨削 | `B-Light` | 左：工序序列（当前工序红底、下一步黄底、道次 6/10）+ 本支辊进度；中：曲线区（误差/参考/圆度/偏心度/磨削电流 五个切换 + 公差带 + RMS）+ 工艺参数只读网格（5×2）；右：实测直径大数字 + 实时数据 8 行 + 补偿状态 |
| 辊形编辑 | `B-Profile` | 左：曲线段列表（可叠加：Polynom / Taper / Radius，各带区间与用途）+ 插入/删除/上移 + 校验面板；中上：辊形预览（合成/主辊形/端部锥度 三条曲线 + 锥度起点标注）；中下：参数网格（由曲线类型 Schema 自动生成） |
| 工序编程 | `B-Steps` | 左：工序序列（11 种工序可任意组合与调序，各带预计时长）+ 预计总时间；中：工艺参数网格（10 项，可编辑）+ 补偿设置（制造商权限）+ 程序步骤复选（8 项） |
| 磨削记录 | `B-Records` | 左：带搜索的记录列表（辊号/类型/辊形/班次/时间/合格）+ 本月支数与合格率；中上：磨削结果 12 项指标；中下：四种曲线切换（磨前磨后辊形 / 误差曲线 / 圆度36点 / 补偿收敛过程） |
| 手动与辅助操作 | `B-Manual` | 左：轴位置(6) + 主轴(4) + 测量与对中（A/B 测头、直径、安装误差、两端比对表 + 超差提示）；右：测量臂(8) / 尾架与套筒(6+2) / 头架中心架与其他(12) 按钮矩阵 |
| 诊断 | `B-Diag` | 左：连接与版本 + 补偿链路 + 双重限幅一致性（NC/PLC 对照）；右：降级级别（全功能/降一级/降二级）+ 报警与事件表 + 机床能力（按配置显示） |

## 与实现的对应关系

- 语义色位 → `Themes/Palette.Light.xaml` 的 `Brush.*` 资源键
- 字号规范 → `Themes/Typography.xaml` 的 `Text.*` 样式
- 卡片/按钮/网格 → `Themes/Controls.xaml`
- 每页底部 8 键 → 页面 ViewModel 的 `FunctionKeys`，由外壳渲染
