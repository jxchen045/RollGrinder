# 界面评估与优化（第二轮测试之后）

依据：第二轮自检结果（`RollGrinder-TestRun-20260923-230616.zip`：仿真 167/167、离线 87 过 3 跳过、英文界面 21 过 2 警告）、
自检截图、现场反馈（"按钮颜色变化时对比度不足、部分按钮超出页面、字号偏小、部分内容超出边界"），
再逐页读 XAML 做一次通盘复查。

判定标准：

| 项目 | 标准 |
|---|---|
| 正文文字 | 对比度 ≥ 4.5 : 1（WCAG AA） |
| 大字（≥ 24 DIP，或粗体 ≥ 18.66 DIP）、禁用态文字、边框等图形 | ≥ 3 : 1 |
| 最小字号 | 15 DIP（站着隔一臂看工控触摸屏） |
| 版面基准 | 1920 × **1010** DIP（4K @ 200 %，扣掉任务栏后的实际客户区，不是 1080） |

## 一、问题清单与处理

### A. 严重

| # | 问题 | 根因 | 处理 |
|---|---|---|---|
| A1 | 真实界面里登录框、用户管理框永远出不来，开机后整页变灰点不动 | ShellWindow.xaml 里这两个浮层被错嵌进了"离开确认"浮层内部，而后者平时是 Collapsed | 三个浮层改为同一层的兄弟并各自命名；新增 `ShellOverlayLayoutTests`（结构守卫）；自检 Session 套件改为检查浮层**确实显示在屏幕上**，不再只看命令层状态 |

### B. 颜色与对比度

| # | 问题 | 实测 | 处理后 |
|---|---|---|---|
| B1 | 主按钮悬停时 WPF 默认模板把底色换成浅灰，白字几乎看不见 | 白字 / #F3F5F8 = **1.09** | 每种按钮都有自己的悬停色、按下色（加深而不是变浅）：白字 / AccentHover 10.21、/ AccentPressed 12.93 |
| B2 | 次按钮按下时同样被默认模板刷成浅蓝 | 1.19 | SurfaceHover 15.07、SurfacePressed 13.23 |
| B3 | 禁用靠 `Opacity=0.4`，红色"停止"键变成粉红、白字发虚 | 白字 / 粉红 = **2.33** | 禁用改为统一的中性外观（DisabledFill + DisabledText + DisabledBorder），文字 4.03，一眼看出"按不动"，不再像另一种颜色的按钮 |
| B4 | 次要文字色 TextMuted 在底部功能条上不够 | 3.59 | #6B7581 → #5A6470：功能条 4.62，白底 6.01 |
| B5 | 次按钮边框在白底上几乎看不出，按钮像一块纯文字 | 1.91 | #B6BCC6 → #8C95A1：3.03 |
| B6 | 键盘操作时看不出焦点在哪（非触摸屏场景） | — | 统一的 `KeyboardFocusRing`：外圈深色 2 px + 内圈白 2 px，深浅底上都看得见；只在键盘导航时出现 |
| B7 | 参数格不适用时靠 `Opacity=0.4`，字发灰且和底色糊在一起 | — | 改为 DisabledFill 底色，文字保持原色 |

实现：新增 `Controls/ButtonStates.cs`（悬停 / 按下 / 禁用三组附加属性），所有按钮样式的模板触发器都从这里取色；
`Controls/ContrastMath.cs` 为纯计算，产品和测试共用。

守卫：`ButtonContrastTests` 沿 BasedOn 链解析每一个带键的按钮样式，逐一核对 常态 / 悬停 / 按下 ≥ 4.5、禁用 ≥ 3.0、
边框 ≥ 3.0、三级文字色在六种底色上 ≥ 4.5。改一个颜色弄坏了对比度，单测直接报出是哪个样式、哪个状态、多少比多少。
自检在运行时再扫一遍屏幕上真正显示的按钮和文字（含半透明叠层的混色），结果进 WARN。

### C. 版面：出界、截断、小屏

| # | 问题 | 根因 | 处理 |
|---|---|---|---|
| C1 | 记录页查询条第二行被切掉 | 上一轮把查询条改成两行，但外框还写着 `Height=56` | 改为 `Height=Auto` |
| C2 | 英文界面下手动页"Clear centring"等按钮文字被切 | 三个按钮放在 StackPanel 里按内容宽度排，超出 560 宽的左栏 | 改为三等分 `UniformGrid`，按钮内边距收小 |
| C3 | 自动页工序矩阵空态提示贴在左边、下面一大片空白 | DockPanel 的非末尾子元素默认靠左停靠 | 空态提示与滚动区放进同一个 Grid，居中 |
| C4 | 表格风格不一（手动页对中表、诊断页事件表各写各的） | 没有公共样式 | 新增 `DataTable` / `DataTableHeader` / `DataTableCell`：行高 40、横线分隔、隔行底色、选中行 SelectionFill |
| C5 | 工序库里不可用的辊形几乎看不见 | 透明度 0.35 | 0.6 |
| C6 | 版面按 1080 高设计，实机只有 1010 | 4K @ 200 % 扣任务栏 | 自检的出界检查改为按窗口实际客户区判断，并同时检查左右上下四个方向，报告出界多少 px |

自检的出界 / 截断检查扩展为：按钮内容超出、文字硬截断（不换行也不省略号，且不在按钮 / 下拉框 / 表格里）、
元素超出所在容器或窗口。每条报告写明元素、方向和像素数。

### D. 字号

| # | 问题 | 处理 |
|---|---|---|
| D1 | 19 处写死 13 / 14 号字（工序矩阵序号、状态角标、快捷键提示、探头标签、记录列表副标题、错误提示等） | 新增字号档 `Size.Caption = 15`，全部改用它 |

### E. 曲线图

| # | 问题 | 处理 |
|---|---|---|
| E1 | 三张图（自动磨削实时曲线、辊形预览、磨削记录）用的是 ScottPlot 默认外观：刻度字约 12 px，隔一臂看不清 | 新增 `Views/PlotTheme.cs`：刻度 15、轴标题 16、图例 15 |
| E2 | 中文轴标题可能显示成方块 | ScottPlot 用自己的渲染器，读不到打包进程序集的 Noto Sans SC；统一指定系统自带的 Microsoft YaHei |
| E3 | 图的底色、网格、文字色与界面不一致 | 运行时从 Palette.Light.xaml 的色位读取，不另写一份 |

### F. 报警文案

| # | 问题 | 处理 |
|---|---|---|
| F1 | 删最后一个制造商账户时报警条显示"800002 工艺数据不合法 • The last manufacturer account cannot be removed or demoted."——标题说的是工艺数据，实际是账户规则；后半句是英文 | 通用标题改为"操作未执行 / Operation not performed"；`DomainException` 可带界面资源键，账户管理的四种拒绝（重名、空密码、最后一个制造商、用户不存在）各有本地化说法，报警条只显示这句话加具体对象（如用户名），英文原文只进日志；这类"规则拦下"降为警告级 |

其余约 50 处领域异常仍是英文原文加通用标题。它们对应的输入在界面上已先做校验（参数范围、必填项），
正常操作碰不到；若第三轮测试里出现了，按同样的方式给它补资源键。

### G. 自检截图失真

第二轮截图里的黑条、黑块在屏幕上并不存在：`RenderTargetBitmap` 只画元素本身，不画窗口背景，透明缝隙存成 JPEG 变黑。
截图前先铺一层窗口底色再画内容。

### H. 鼠标停在按钮上闪烁（第三轮反馈，B 项改动引入）

| # | 问题 | 根因 | 处理 |
|---|---|---|---|
| H1 | 鼠标停在按钮上不动，按钮颜色一闪一闪 | B 项把悬停色、按下色改成在模板触发器里用 `Binding` 取值。取值一落空，底色就是 null；WPF 里 null 底色的区域不参与命中测试 → 鼠标"掉出"按钮 → 悬停撤销、底色恢复 → 鼠标又"落回" → 再悬停……每帧来回一次 | 按钮模板改成**叠层**：常态 / 悬停 / 按下 / 禁用各一层 Border，颜色用 `TemplateBinding` 一次绑死，触发器只切换哪层可见，触发器里不再有任何 Binding；最底层垫一块透明的命中层，整块按钮在任何状态下都接得住鼠标 |
| H2 | 底部功能条、手动页按钮的提示框可能盖到鼠标下面，把悬停"抢走" | 提示框默认跟着鼠标定位，靠近屏幕下沿时会翻到鼠标上方并压住光标 | 提示框改为挂在按钮上：功能条、手动动作键在按钮上方，顶栏在下方，程序步骤开关在右侧——永远不压住按钮本身 |
| H3 | 曲线切换键（误差 / 参考 / 圆度 / 偏心 / 电流，记录页四条曲线）看不出当前选的是哪条 | 选中状态绑在 `Tag` 上，但样式里没有任何东西读 `Tag`——从一开始就没生效 | 新增 `ButtonStates.IsSelected`，选中时实心强调色；参数格里的选项键改用同一个开关，`SegmentButtonSelected` 这个没人用的样式删掉 |
| H4 | 未登记到 tagmap 的手动动作有两套"灰"：禁用层 + 一条额外的压暗触发器 | 历史遗留；该动作本来就是禁用态（`IsEnabled = IsMapped && IsAllowed`） | 删掉多余的触发器，只保留统一的禁用外观 |
| H5 | 曲线外观每次重画都重新套一遍 | `PlotTheme.Apply` 放在了每次 `Clear()` 之后 | 只在控件创建时套一次（`Clear()` 只清曲线，不动坐标轴样式） |

守卫：
- `ControlTemplateStabilityTests`：任何 XAML 里模板触发器的 Setter 不得含 Binding；Button / ToggleButton 模板的根元素必须有底色。
  拿上一版 Controls.xaml 验证过，会报出 `Chrome.Background`。
- `ButtonContrastTests` 扩展为核算**样式触发器生效后**的样子（选中、保持型动作点亮、待确认），不只看基础 Setter。
- 自检新增运行时命中测试 `FindHitTestHoles`：每个可按的按钮取中心和四角 5 个点做命中测试，
  落到按钮外面的上级元素就报 `hit-test holes (hover flicker)` 警告。

## 二、没有改、留待确认的

- **深色主题**：Palette 只有浅色一套。车间光照强，浅色是对的；夜班是否要深色需现场决定。
- **手动页在 1010 高下**：左栏测量表格会变矮（内部可滚动，不出界）。若现场觉得行数太少，可以把轴位置卡改为两行紧凑布局，需看实机截图再定。
