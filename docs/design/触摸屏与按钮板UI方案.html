触摸屏与按钮板：界面修改方案

甲方答复 Q1：以前的项目有配触摸屏一体机的，也有独立工控机加触摸显示器的；日常操作与编程都在触摸屏上，头架与砂轮旋转、复位、急停这类按钮单独做一块按钮板。本方案据此重新划分"屏幕管什么、按钮板管什么"，把界面从"按键优先"改成"触摸优先"，并列出分期与要甲方确认的问题。本稿只提方案，源代码暂不改动。

0结论

分工：屏幕管"设定与查看"，按钮板管"动与停"头架、砂轮旋转，复位，急停只在按钮板上。屏幕上这几项只显示状态、不再给按键；哪些动作归按钮板由 machine.json 登记，各项目按实际按钮板配。
输入：自带数字键盘点任何数值格，弹出带名称、单位、范围的大键盘，"下一项"连续输入。名称尽量自动生成，要打中文时才调 Windows 触摸键盘。
看不见的都要改成看得见现在"为什么按不了"只在鼠标悬停时出现，触摸屏上永远看不到；改成点一下灰键就在屏幕上写出原因。悬停效果、手指拖不动的列表也一并改。
软键结构保留底部 8 横、右侧 8 竖的软键条保留：位置固定、面积大，本来就适合触摸，也和西门子 Operate 在触摸面板上的用法一致。键盘快捷键继续有效，办公室电脑编程照样用。

第一期（必须在现场试运行前完成）约 2 周。另有一项取决于甲方用的屏幕：如果有 15″/17″ 的 4:3、5:4 小屏，还要加一套紧凑版面，约再 1.5 周。

1新条件带来的变化

甲方说明对界面意味着什么
日常操作、编程都在触摸屏上手指是主要输入：没有悬停、没有右键、没有滚轮，点的位置有几毫米误差；可能戴手套。机床旁未必有键盘——所有数值、名称都要能在屏幕上输入。
头架、砂轮旋转、复位、急停单独做按钮板会让机床"动起来""停下来"的操作归按钮板（硬线、有 PLC 互锁）。屏幕上再放一套同样的按钮是重复，还可能让人以为屏幕能停机。屏幕要做的是把这些操作的结果显示清楚：转没转、多少转、急停了没有。
有一体机，也有独立工控机 + 触摸显示器屏幕尺寸、分辨率、长宽比、触摸类型（电容 / 电阻）因项目而异；分体机还有"触摸对不准屏幕""程序跑到另一块屏上"的问题。界面要能按屏幕配置，装机要有检查清单。

这也回答了修改稿里的 Q1。当时的建议是"底部 8 横 + 右侧 8 竖软键、触摸兼容"，软键结构这次保留；要改的是优先级：触摸优先、键盘兼容，运动与安全交给实体按钮。

3设计原则（修订）

修改稿第 4 节的五条原则中，第 1 条改为下面这条，其余四条不变（图形辅助输入、数据分层、边编边校验、名称唯一）：

原则 1（修订）

触摸优先、键盘兼容；动与停归按钮板。

  • 每个操作都能只用手指完成，每个可点的东西不小于 15 mm；不依赖悬停、右键、滚轮、双击。
  • 接了键盘照样能用：F1–F8、Shift+F1–F8、Tab、回车都保留，办公室电脑编程不受影响。
  • 让机床动起来、停下来、复位、急停的操作在按钮板上；屏幕只发"设定"与机构动作的请求，并把按钮板操作的结果显示出来。
  • 凡是"为什么"——为什么灰、为什么没发出去、为什么存不进——都直接写在屏幕上，不藏在提示框里。

4方案

A 屏幕与按钮板分工

A1 哪些动作归按钮板，由 machine.json 登记，不写死。新增一项 panelActions，列出这台机床按钮板上有的动作（例如 headstock.forward、headstock.reverse、wheel.run、cycle.start、coolant）。登记了的动作：屏幕上不给按键，只保留状态灯；没登记的照旧在屏幕上。不同项目的按钮板不一样，改配置就行，代码里没有"if 按钮板"。

  • 显示名称、单位、原值、允许范围；超出范围时读数变红、"确认"变灰，并写出原因（和现在的边编边校验一致）。
  • "下一项 / 上一项"直接跳到下一个参数格，编一道工序不用反复点格子；点表里"下一项"按行、列顺序走。
  • 工序简图照旧跟着亮：键盘开着时，图上亮的就是正在输入的那一项。
  • 只在触摸时弹出；接了键盘、用鼠标点，照旧直接打字。hmi.json 加一项 onScreenKeypad：自动 / 总是 / 从不。
  • 选项型参数（进给方式、插值方式、开关）本来就是分段键，不需要键盘。

B2 文字输入：先少打字，再给键盘。

  • 自动起名：辊形按"类型 + 主参数 + 日期"（如"凸度300-0928"），程序按"工序数 + 日期"，另存为默认"原名-副本"（已有）。大多数时候直接按"确认"。
  • 辊号、作业号、搜索、口令这类字母数字：用自带的全键盘（字母、数字、- _ .），和数字键盘同一种样式。
  • 中文名称：输入框旁边一个"中文"键，调出 Windows 触摸键盘（带拼音输入法）；只在要打中文时出现。Windows 触摸键盘在全屏程序里的表现要在目标机器上实测（见 H）。
  • 登录：用户名已经是一人一键；操作者可以用 4–6 位数字 PIN（数字键盘），管理员、制造商仍用口令。

  • 手指拖动列表：所有列表、表格、长表单打开触摸平移；长列表另加"上一页 / 下一页"两个大键，戴手套时拖不动也能翻。
  • 去掉悬停效果：最后一次输入来自触摸时，不显示悬停颜色（解决"点过的键一直亮着"）；按下的反馈加深，手指按住就能看见。
  • 关掉"长按 = 右键"：Windows 默认长按会出一个方框并当成右键，按住确认（D）时会冲突。
  • 曲线图默认锁定：手指碰图不拖不缩；图角上"放大 / 复位"两个键；磨削中不会被误碰改掉视图。
  • 快捷键标注按需显示：hmi.json 的 showKeyboardHints：自动（检测到键盘才显示）/ 显示 / 不显示。没键盘的机床上，软键只写字，字更大。
  • 擦屏模式：页面菜单里一个"擦屏幕"键：触摸停用 20 秒，屏幕上倒计时。触摸屏油污多，擦屏时不会误按。

D 危险动作的确认：按住，不是按两下

现在的"4 秒内按两下"在触摸屏上容易被一个快速误点两下触发。改为按住约 0.8 秒：按下后键上出现一圈进度，满了才发出；中途松手就取消。

  • 按住不等于点动。命令在进度满的那一刻发一次（仍是脉冲，PLC 上升沿触发），之后按着、松开都不再有作用；键上写"按住确认"，免得被理解成"按着才动"。
  • 用在：套筒缩回、尾架后退、拨盘收回、两侧托瓦降、辅助循环、各轴归位、下发 NC、工序跳转、提前结束、屏幕上的启动（如保留）、删除这一行、清空辊形。
  • 接键盘时仍可"按两下"（两次之间至少隔 0.3 秒，防止键盘连击）。
  • 这些动作里会切削、会让大件动的，大多已归按钮板（A1）；屏幕上剩下的危险键本来就少。

E 看不见的提示改成看得见

底部软键条上方加一行说明行（高 40 px，平时空着）。点一个灰键，说明行写出为什么（例如"下发 NC：作业还有 2 处问题，见核对页"），4 秒后消失；手动动作、程序步骤开关、辊形镜像框同样处理。鼠标悬停提示保留给办公室电脑。

F 直接点选（触摸的长处）

  • 辊形预览：点曲线上的某一段就选中那一段（现在要去左边列表里点）。
  • 工序简图：点图上的某个量（f、ae、n……）就跳到那个参数并弹出键盘。
  • 状态灯：点状态带上的"尾架"灯，跳到手动页"尾架套筒"；点"急停"红条，跳到报警列表。
  • 自动页工序序列：点一行看这道工序的参数（跳到此工序仍是按住确认）。
  • 报警条：点一下展开报警列表（已有），列表里点一条看说明。

建议：新项目统一选 21.5″ 或 24″、1920×1080、投射电容（支持手套模式）、前面板 IP65 的触摸屏，一体机与分体机都按这个规格，界面只维护一套版面。已交付项目若是 4:3 / 5:4 的小屏，再做一套紧凑版面：三栏页改为两栏加标签切换，状态带收成一行图标，软键条宽度不变。是否要做看 Q13 的答复。

分体机要多管两件事：

  • hmi.json 加 display：程序全屏放在哪块屏上（按序号或"触摸屏"），开机就在那块屏上，不会跑到维护用的第二块屏上。
  • 触摸映射与校准：显示器换了接口或多接一块屏后，触摸会落到别的屏上。装机清单里写明校准步骤（H）。

H 装机与 Windows 设置（不在代码里，写进装机清单）

  • 开机自动登录 Windows 专用账号，自动启动上位机全屏；关掉睡眠、屏保、自动更新重启。
  • 关掉屏幕边缘滑动（从边上一划会拉出系统菜单），关掉"长按 = 右键"、触摸视觉反馈。
  • 用自带键盘时关掉 Windows 触摸键盘的自动弹出；中文输入时由"中文"键显式调出。在目标机器上实测一次。
  • 分体机：Windows"平板电脑设置"里把触摸映射到那块显示器，并做一次校准；电阻屏每年校准一次。
  • 触摸屏的手套模式按现场要求打开（投射电容屏在显示器设置里）。
  • 装机后跑一遍自检（加一组"触摸"用例：键盘弹出、说明行、按住确认、列表拖动），结果随交付资料留档。

5保持不变的

  • 底部 8 横 + 右侧 8 竖软键的结构、每页的软键安排、▸ 子菜单与"« 返回"。固定位置的大键本来就适合触摸；西门子 Operate 在触摸面板上也是这套。
  • 数据分层、工序简图与说明行、边编边校验、名称唯一、权限表、状态带、补偿子视图、配置编辑器。
  • 最高原则不变：上位机只做设定、显示、记录，不在实时控制回路里；屏幕上的机构动作仍是"请求"，由 PLC 互锁决定能不能动。
  • 键盘操作全部保留（办公室电脑离线编程、维护人员带键盘时）。
