上位机与 NC 接口约定

本文是《轧辊与磨削方案设计说明》第 0 期的交付物，约定上位机（RGX）与 NC 之间的数据交换：作业下发、运行中改参数、道次数据回传、辊形点列、补偿与 DRF。上位机只按逻辑名读写，物理地址全部由 tagmap.json 决定；本文给出的地址是建议值，以 NC 程序员定稿为准。

0目的与原则

上位机不在控制回路里补偿、折返、进给全部由 NC 完成。上位机关掉、断网、卡死，机床照常把这支辊磨完。
NC 只在启动前等上位机唯一允许的等待：循环启动前参数必须完整有效。运动中 NC 程序不得出现等待上位机信号的 WAIT 或条件循环。
一个变量只有一个写方每个变量要么上位机写、要么 NC 写，不共用；状态靠序号比较，不靠"置位—清零"。
序号最后写写一组数据时，数据先写完，最后写序号或有效标志；读方看到序号变化才读，避免读到一半。
命令位是脉冲沿用现有约定：上位机写 true → 等脉宽 → 写 false，PLC 上升沿触发并自复位。

2作业下发握手

现状与问题

上位机下发时把全部参数写一遍，最后写 parametersValid = true。但开始写之前没有先把它置为 false：如果上一份作业留下的是 true，上位机写到一半崩溃，NC 会把"一半新、一半旧"的参数当成有效。

约定

① 写 valid = false→② 读回确认为 false→③ 写全部参数→④ 写下发序号 downloadSeq + 1→⑤ 写 valid = true
  • NC 只在循环启动时检查：valid 不为 true 拒绝启动并报警；为 true 时把 downloadSeq 锁存到 acceptedSeq。上位机读 acceptedSeq 确认"NC 正在磨的就是我下发的那一份"，并写进磨削记录。
  • 运动中 NC 不再看 valid；上位机也不得在加工中重新下发整份作业（现有软件已在核对页挡住）。
  • 中断后续磨：沿用同一份参数时不重新下发，acceptedSeq 不变；重新量过磨前直径需要重新下发的，走完整流程。
  • 上位机在 ①–⑤ 任何一步失败：valid 停在 false，NC 拒绝启动，界面提示"下发未完成"。

3运行中改参数（原子生效）

现状与问题

现在改参数是直接重写那一道工序的 R 参数，NC 在下一道次开始时读取，不重新置有效标志。问题：一道工序有多个参数，上位机逐个写的过程中 NC 恰好到了道次开始，就会读到"进给已改、道次数未改"这种组合；上位机也不知道新值是否已生效。

约定：暂存区 + 序号

变量写方含义
job.edit.stepOrder上位机要改第几道工序
job.edit.*（与 job.step.* 同名的一组单值）上位机该工序改后的全部参数（整组写，不只写改动项）
job.edit.seq上位机改参数序号，暂存区写完后加一
job.edit.appliedSeqNCNC 已采用的序号
  • 上位机：只有在 appliedSeq == seq（上一次已被采用）时才写暂存区；写完全部参数后最后写 seq + 1。否则提示"上一次修改尚未生效"，不收新的修改。
  • NC：每个道次开始时比较，若 seq ≠ appliedSeq，把暂存区整组拷到对应工序槽位，再写 appliedSeq = seq。拷贝在 NC 程序内完成，对 NC 自己是原子的。NC 不等待，不比较就继续。
  • 无竞争：暂存区只有在"已采用"状态下才会被上位机改写，NC 只在序号变化后读它，两方不会同时操作同一块数据。
  • 上位机显示："已下发，等待生效" → 看到 appliedSeq 追上后显示"第 n 道起生效"，记录写入生效道次；超过一道次仍未生效显示"未生效"，不重发、不干预。
  • 目标工序已磨完、或在当前道次改了不允许在线调整的参数：上位机侧照现有规则挡住，不写暂存区。

4道次数据环形缓冲

用途：磨削记录的"道次表"（每道次左右折返的实际值、本道次补偿量），用于追溯端部质量与补偿收敛。只用于记录，所以采用 NC 不等上位机的环形缓冲。

4.1 结构

变量写方含义
pass.slotCountNC（常量）槽位数 N，建议 16
pass.writeSeqNC已写完的最后一行的序号（从作业开始计，单调递增）
pass.overflowCountNC覆盖了未读行的次数
pass.readSeq上位机上位机已存库的最后序号（仅供 NC 判断溢出）
pass.row[k]，k = seq mod NNC一行，字段见 4.2

4.2 一行的字段（建议 16 个实数）

#字段单位NC 侧来源（候选，待确认）
0行序号 seq（NC 最后写）—计数器
1工序序号—即 job.currentStepOrder
2道次号—即 job.currentPass
3–6左折返：实际 Z、实际停留时间、折返时进给倍率、折返时实际 Xmm、s、%、mm折返瞬间同步动作锁存：Z / X 实际位置、倍率、停留计时
7–10右折返：同上mm、s、%、mm同上
11本道次行程间补偿量mm（半径）NC 补偿程序
12补偿版本号—即 compensation.strokeVersion
13DRF 偏置（X）mmDRF 偏置系统变量；自动时禁用则恒 0
14本道次平均磨削电流（可选）ANC 累加平均
15备用——

"折返瞬间"怎么界定、用哪些系统变量，由 NC 程序员按现有折返程序定（候选：Z 轴到达折返位置的程序段结束、或停留开始时，用同步动作把值写入 GUD）。字段顺序可调整，调整后同步改 tagmap 与本表。

4.3 NC 侧规则

每道次结束（右折返之后或按程序定义）：
  k = (writeSeq + 1) mod N
  若 writeSeq + 1 − readSeq > N：overflowCount += 1   （仍然覆盖，不等）
  写 row[k] 的字段 1–15
  写 row[k].seq = writeSeq + 1      ← 行内最后写
  writeSeq = writeSeq + 1           ← 全局最后写
作业开始（循环启动锁存 acceptedSeq 时）：writeSeq = 0，overflowCount = 0，各行 seq 清 0

禁止：任何 WAIT、等待 readSeq 的循环、因上位机不读而报警停机。

4.4 上位机侧规则

周期读 writeSeq（与现有监视同周期，约 100–250 ms）
对每个 s ∈ (readSeq, writeSeq]：
  k = s mod N
  读 row[k].seq → a；读字段 1–15；再读 row[k].seq → b
  若 a == b == s：存库，readSeq = s
  若 a ≠ s 或 b ≠ s：该行已被覆盖 → 记"缺第 s 道"，readSeq = s
写回 readSeq
  • 上位机给每行打上读取时间戳；NC 不需要提供时间。
  • 记录里缺号显示"道次表不完整，缺第 x–y 道"，并记一条通信异常事件；不报警、不干预机床。
  • 看门狗：机床处于加工中、且连续 T 秒（默认 10 s，hmi.json 可配）读不到任何变量更新时，界面显示"道次数据未更新"并记事件。只提示。
  • 缓冲深度：N = 16 时，一道次按最短 30 s 算，上位机可离线约 8 分钟不丢数据。

5辊形点列

  • 坐标：bodyPositionMm 现在是 0 到辊身长度（等距采样），0 在辊身哪一端（头架侧 / 尾架侧）需确认。上位机内部按辊身中心为 0 定义辊形，下发时换算，NC 侧不变。
  • NC 按位置数组插值，不假设等距：上位机今后会在分段交界处补点（凸度段与圆柱段的交界不落在等距点上时，等距采样会把拐点削平），点距因此不再相等。NC 在相邻两点之间按 bodyPositionMm 查找区间。
  • 插值方式：线性。上位机负责保证弦高误差：任意两点之间，原曲线与连线的最大偏差 ≤ 0.5 µm（半径），超出则在该区间加密；点数仍受数组长度（现为 101）限制，放不下时下发前报错，不静默降精度。估算：2000 mm 辊身、凸度 0.30 mm 的抛物线，101 点线性插值的弦高误差约 0.03 µm，远小于门槛。
  • 点数：job.profile.pointCount 给出有效点数，NC 只用前 n 个。
  • 端部截取 / 延伸（设计说明第 4.5 节）在上位机完成，NC 收到的已是本次辊身上的点列。

6补偿与 DRF

行程间补偿

  • 由 NC 完成，上位机只读：compensation.strokeVersion、realtimeOffsetMm、degradationLevel、前馈 a / b。
  • 每道次的补偿量与版本号进道次缓冲（第 4 节字段 11–12），上位机不再靠 100 ms 监视去"赶上"版本号变化。
  • 上位机侧的补偿曲线（测量后生成）只影响下一次下发的辊形点列，不在运行中写 NC。

DRF 手轮偏置

  • 先确认：自动磨削时是否允许操作工用 DRF。建议默认禁止（DRF 改变实际磨削位置，却不在任何参数里）。
  • 若允许：NC 在每道次行里报当前 DRF（字段 13）；上位机发现值变化就记一条"决定"类事件（时间、道次、变化前后值）。另外提供一个单值变量 drf.offsetXMm 供界面实时显示。

8联调测试用例

先在上位机仿真（RollGrinder.Sim）里按本约定实现 NC 一侧逻辑跑通，再到机床联调。

#场景期望
1下发写到一半杀掉上位机，然后按循环启动NC 拒绝启动（valid = false）
2正常下发后启动acceptedSeq == downloadSeq，记录中一致
3运行中改一道工序的三个参数NC 在某一道次开始时整组采用，appliedSeq 追上；记录写明生效道次；不出现部分采用
4上一次修改未生效时再改上位机拒收，提示"上一次修改尚未生效"
5加工中拔掉上位机网线 5 分钟再插上机床不停、不报警；恢复后补读全部道次，无缺号
6拔网线超过缓冲深度机床不停；overflowCount 增加；记录标"缺第 x–y 道"
7上位机进程卡死（不退出、不读）同 5 / 6；机床照常磨完
8辊形含分段交界、点距不等NC 按位置插值，测量轮廓与下发曲线偏差在公差内
9（若允许 DRF）自动中摇 DRF道次行字段 13 变化，记录有对应事件
