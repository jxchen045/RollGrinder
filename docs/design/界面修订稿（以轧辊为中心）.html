以轧辊为中心的界面修订

把界面最终稿与关系设计说明逐项对照，找出 10 处差距；再从操作工、工艺员、车间管理者、设备厂商、质检五个角色评审三轮，修正 21 处问题。结果：左栏加"轧辊"、取消库区；作业改为"待磨清单 + 一页核对"；台账、批量改、库保存影响、报表总览、磨完结论各有一页，两档屏幕都放得下。

左栏机床 · 轧辊 · 辊形 · 工艺 · 砂轮 · 记录 · 诊断；库区取消，各库回到各自的区。

轧辊区台账（计划、寿命条、履历）、新登记、批量改计划、导入 / 导出、已作废。

3.2 规则补充（并入界面最终稿 4.4 / 4.5）

  • 三选一：竖键 8 / 回车 = 稳妥项；竖键 6 = 有后果的另一项（带"…"，再问一次）；竖键 7 / Esc = 取消。
  • 自动取消：5 秒自动取消只用于会让机床动的确认；选择题（仅本次 / 变更、更新 / 另存为新、原因）不自动取消。
  • 原因：竖键列常用项（试磨 · 临时调机架 · 设备原因 · 返磨 · 其他…），只有"其他"要输入。
  • 单位：直径、磨削量、去除量用 mm（直径，3 位小数）；辊形、误差、圆度用 µm。
  • 核对清单：通过项折叠为"✓ n 项核对通过 展开 ▸"；不通过红、提示橙，逐条展开写原因；新辊首次核对默认展开。
  • 例外标记：与台账计划不同的行底色橙；路径条、履历、记录列表都写"例外 / 变更 / 返磨 / 中断"。
  • 版本：辊形、程序名称后带版本（凸度300 v3），快照与记录照写。
