轧辊与磨削方案

以轧辊为中心、强绑定：辊形和工艺不再是被很多支辊共同引用的库条目，而是归某一支辊所有的"磨削方案"。一支辊名下可以有多个方案，其中一个是当前方案；每磨一次开一份作业，作业取当前方案、填这一次的数、下发；磨削记录写清按哪个方案、本次调了什么、实际怎么磨的。方案由工艺员定结构和范围，操作工在范围内调这一次的数。

0结论

辊是唯一的一支辊一个辊号，几何尺寸只在轧辊上；方案、作业、记录都挂在辊号下。
方案归辊所有磨削方案 = 辊形 + 工艺；长度取自所属轧辊，不再有参考轧辊、运行时 2% 套用规则。
一个当前方案一支辊可以有多个方案，同一时刻一个当前，其余为历史；方案可带"用途 / 机架"标签。
用过即冻结被作业用过的方案不能改，改就另存为新方案。不再需要版本号、在用清单、停用。
长度按中心对齐辊形按名义长度、以辊身中心为基准定义；长度有差异时两端截取或延伸，任何时候都不等比伸缩。
复用靠复制新辊、新方案都可以从已有的辊或标准模板复制，并记住来源；不做批量同步。
两层参数工艺员定结构与可调范围；操作工在范围内调这一次的数，只进这一次的快照与记录。
记录分轻重决定逐条记；倍率这类实时调节按道次存摘要；折返与补偿由 NC 锁存、每道次一行；过程曲线降采样。

1为什么改

现在的模型

辊形库、程序库与具体轧辊无关；台账的"计划"引用一条辊形、一支程序；作业时按这支辊把它们实例化（辊形按 2% 规则套到辊身、粗磨吸收余量差），下发并存快照。

现场使用中的困惑

  • 辊形要填"参考轧辊"、运行时还要按 2% 规则伸缩，工艺员不容易想清楚"我画的到底是哪根辊"。
  • 改一条被引用的辊形要回答"有 n 支辊在用，更新还是另存为"，并配套版本、在用清单、停用，概念多。
  • 工艺员和操作工的直觉是"这支辊怎么磨"，而不是"库里哪个条目"。

行业背景（决定了设计取舍）

  • 磨辊是高频操作：工作辊频繁下机重磨，支承辊几周一磨。软件首先要让"按既定方案再磨一次"最快、最不易错。
  • 改辊形是低频、高影响操作：每个机架的辊形由轧机与产品决定，一般在换轧制计划、工艺优化时才改，按周、按月计。
  • 因此不做"一键批量同步"：低频操作不值得为它承担一次改几十支辊的风险（第 4.6 节用逐支提示代替）。
  • 辊形里的长度在行业里通常取轧机 / 辊型设计的名义长度，同一机架、同一图号的辊名义长度相同；跨辊复制时长度不同的情况很少（第 4.5 节）。

下发方式不变：上位机只往 NC 的固定变量写数（辊形是两个定长数组，工序参数是一组固定变量），主程序常驻 NC，不生成、不编译、不覆盖任何程序。方案归辊所有还是共享，只是上位机数据库里的区别；NC 每次收到的格式、地址都一样，不会造成 NC 内存碎片或触发复位。每次下发前先由方案与作业合成一份快照，这一点与现在相同。

4磨削方案

4.1 内容

  • 辊形：分段（圆柱、凸度、锥度、CVC、点表，可组合；不修形的端部写成圆柱段），形状参数，公差。按"设计名义长度"定义，轴向坐标以辊身中心为 0；新建时名义长度取自所属轧辊的名义辊身长度，方案保存后随方案一起保存，不再跟着台账变。
  • 工艺：工序顺序与类型（开始、结束固定），每道工序参数的标准值与可调范围，标准余量与余量分配，程序步骤默认开关。
  • 属性：方案号（这支辊内编号，如"方案 3"）、名称、用途 / 机架标签（可选）、来源、建立人与时间、是否当前、是否已冻结。

4.2 当前方案与历史

  • 一支辊同一时刻只有一个当前方案；待磨清单和作业核对默认用它。
  • 其余为历史方案，可查看、复制、重新设为当前（例如辊调回原机架）。换当前方案记一条改动。
  • 这一次想用别的方案：作业核对页"换方案"，只影响这一次（必须选原因）。

4.3 用过即冻结

  • 没被作业用过的方案可以随意修改、删除。
  • 被任何一次作业用过的方案冻结：不能改、不能删。工艺员打开冻结方案修改，按保存时自动另存为新方案并设为当前，提示"原方案已用于磨削，已另存为方案 n"。
  • 效果：任何一条记录指向的方案内容永远不变；取代原来的版本号、在用清单、更新或另存为、停用。
  • 不设版本链：改了就是一个新方案（新编号），来源记为原方案。工艺员改方案频率低、不会乱改，存储影响可以忽略；方案列表默认只显示当前方案和最近用过的几个，其余收在"全部方案"里。

4.4 来源

每个方案记住从哪里来：空白新建、复制自本辊方案 n、复制自轧辊 X 的方案 n、复制自标准模板 Y、存自作业 J 的调整。界面标出"与来源一致 / 已改动"。

4.5 长度不一致时：一条规则，两个场合

两个场合会遇到"方案的名义长度"和"要磨的辊身长度"不一致：跨辊复制（另一支辊的名义长度不同），作业下发（这支辊的实测辊身长度与名义长度不同，例如端面返修后变短）。两处用同一条规则：

  • 以辊身中心为基准对齐，不做等比伸缩。等比伸缩会改变凸度的曲率、CVC 的系数和锥度的斜率，等于悄悄换了一条辊形——这正是原来 2% 规则让人困惑的原因。
  • 差值不超过可配置门槛（默认 1 mm）视为相同，不提示。
辊形类型辊身更短辊身稍长（在容差内）超出容差
凸度、锥度、圆柱等解析段两端段保持绝对长度，中间段按新长度铺满（形状参数不变）复制：预览新旧曲线，确认后套用；下发：拦下，请工艺员处理
CVC、点表以中心为基准截掉两端多出的部分（精确，因为曲线本来按轧机坐标定义）两端按切线延伸，预览确认不套用：多项式外推会发散；请在本辊上重新输入或导入
  • 容差分两个：复制用的名义长度差门槛；下发用的"实测与名义"容差（默认取机床配置，建议不超过 2% 且不超过若干毫米，待甲方定）。
  • 下发时发生截取或延伸：核对页显示一行"实测比名义短 3.0 mm，两端各截 1.5 mm"，操作工不需要找工艺员；下发快照写明对齐方式与差值。
  • 工艺部分与几何无关，复制时直接复制。
  • CVC 曲线的基准（辊身中心，还是辊身端面加窜辊量）需甲方确认；若基准不是中心，本节 CVC 一行按实际基准改写。

截取与延伸处的连续性

  • 截取不产生台阶：截取只是把原曲线的定义域缩短，留下部分逐点与原曲线相同，辊身内没有任何跳变；辊身端点的半径偏差就是原曲线在该点的值。点表截在两个点之间时，端点值按与 NC 相同的插值方式算出（插值方式见第 10 节第 0 期约定），不另取近似。
  • 延伸保证高度与斜率连续：切线延伸在接点处值与一阶导数连续，曲率由原值变为 0；延伸长度每端不超过下发容差的一半（毫米级）。
  • 只发生在端部非工作区：方案可填"端部非工作区宽度"（倒角、边部过渡，默认取端部圆柱段长度）。截取或延伸量超出这个宽度时按"超出容差"处理（复制须确认、下发拦下）。这样工作区内的曲线始终是原曲线，不会被改形。
  • 不采用余弦平滑过渡：在工作区附近加过渡段会改变有效辊形，与"工作区内曲线不变"相冲突；端部需要的过渡应由工艺员作为辊形的一段（如端部圆柱段、倒角段）显式定义。
  • 预览中标出截取 / 延伸位置与端部非工作区边界。

4.6 标准模板与"标准更新了"

  • 工艺员可维护少量标准模板（标准辊形、标准工艺），仅作复制起点，不被轧辊引用。
  • 标准模板改了，不批量改任何轧辊。某支辊下次来磨时，若它的当前方案复制自该模板且模板已更新，作业核对页提示一次："复制自'F3 凸度 300'，标准已更新，本次改用新的吗？"——确认则从新模板复制出新方案并设为当前。
  • 工艺员更新模板时可勾选"必须采用"：此后复制自该模板的辊来磨时，核对页直接换成从新模板复制的方案，操作工只能确认、不能沿用旧方案。用于纠正明显问题或全机架统一优化——同一机架的辊本来就轮流来磨，一个换辊周期内全部过一遍。
  • "必须采用"不抹掉任何方案：
    • 它只是从新模板复制出一个新方案并设为当前；原当前方案保留为历史方案（用过的本来就冻结，没用过的此时也一并冻结），可随时查看、复制或重新设为当前。核对页提示："标准模板'F3 凸度 300'已强制更新，原方案 n 已转为历史，本次使用新方案 m。"换方案记一条改动。
    • 操作工上次的本次调整不在方案里，不受影响；核对页照常提示"上次调整过 …"，但仅作参考，不自动套到新方案上。
  • 特批方案由工艺员在勾选时处理，不留给现场：勾选"必须采用"时，系统列出所有当前方案复制自该模板的轧辊，并标出其中"已改动"（与来源不一致，通常是特批）的：
    • "与来源一致"的辊：按"必须采用"执行；
    • "已改动"的辊：工艺员逐支选"同样强制""改为普通提示"或"不提示"，默认"改为普通提示"。
    这样现场核对时不会出现"强制更新把特批方案换掉"的情况。只对模板列出复制关系，轧辊方案之间仍不做在用清单。
  • 好处：每次只影响一支辊、在磨前、有人确认；在轧机上的辊天然不受影响。

4.7 工艺参数的表达（待定）

头架转速、拖板速度目前按机床量（r/min、mm/min）存。可选改为按工艺量存（工件线速度 m/min、每转进给），作业时按这支辊换算；方案归辊后这一项不再是必须，见第 11 节待确认。

5.2 三道限制

  1. 机床限制（制造商，硬上限）：机床能力。谁都超不过。
  2. 方案范围（工艺员）：每个可调参数的上下限或调整幅度；未填的取机床配置里的默认范围表。
  3. 作业取值（操作工）：在前两道以内按这支辊的实际情况调；超出不收并说明原因。

5.3 默认可调范围（初稿，待甲方工艺员确认）

参数作业里

5.4 调整怎么呈现与记录

  • 核对页与自动页参数区标出"方案值 → 本次值"，核对页顶部写"本次调整 n 项"。
  • 每项调整记入作业：参数、方案值、本次值、人、时间（核对时与运行中都算）。运行中调整仍走"先标红、确认才写、NC 下一道次读取"。
  • 下次磨默认回到方案值；该辊上次有调整时，核对页提示"上次调整过 …，要沿用吗"。
  • 记录页对有调整的作业提供 存为新方案…（工艺员权限），新方案来源记为该作业。

6记录：存什么、不存什么

类别例子怎么存
决定下发的方案值、作业里的调整、换方案及原因、长度对齐、DRF 手轮偏置的每次变化逐条记
道次数据每道次左右折返点的实际值、本道次补偿量每道次一行（道次表，见下）
实时调节进给 / 砂轮 / 头架倍率（机床面板上随手拧）不逐条记，按道次或工序存摘要

道次表（折返与补偿）

端部质量（倒角、环痕、过切）和行程间补偿是否收敛，取决于每次折返时发生了什么，平均值看不出来。因此每道次记一行，左右折返各一组：

  • 实际折返 Z 位置、实际停留时间、折返时的倍率；
  • 本道次行程间补偿量与补偿版本号；
  • DRF 偏置（若自动时允许使用）。

由 NC 锁存，上位机每道次读一次：上位机经 OPC UA 订阅拿不到可靠的 10 ms 级数据（常规约 100 ms 且不确定），在上位机提高采样率换来的是不准的数据。做法是 NC 在折返瞬间用同步动作把上述值写进缓冲变量，上位机读走后写入记录。数据量小：一支辊几十道、约一百行。

接口约束：NC 永远不等上位机

道次数据只用于记录，上位机不在补偿回路里，所以 NC 不得为它等待上位机：上位机慢了、断了、程序卡死，机床照常磨完。约定为环形缓冲 + 序号，而不是"置位—等清零"：

  • NC 侧：N 个槽位（建议 ≥ 16，覆盖上位机最长几分钟不在线）；每写完一行，写指针加一、该行带递增序号；写指针追上读指针时覆盖最旧一行并把溢出计数加一。NC 程序中不得出现等待上位机信号的 WAIT / 条件循环。
  • 上位机侧：发现写指针变化就读出新行，按序号校验，写完数据库后更新读指针（读指针只供 NC 判断溢出，NC 不因它停顿）。
  • 读一行用"读序号—读数据—再读序号"，两次序号一致才算完整，避免读到写了一半的行。
  • 缺号或溢出：记录里标"道次表不完整，缺第 x–y 道"，并记一条通信异常事件；不报警停机。
  • 看门狗：上位机连续 T 秒（默认 10 s，可配置）收不到写指针 / NC 心跳的更新且 NC 处于加工中，在界面显示"道次数据未更新"并记事件；同样只提示，不干预机床。

对比：作业下发前的 parametersValid 握手是另一类——NC 在启动前必须等到参数完整才能开始，这里等待是对的；它只发生在循环启动前，不在运动中。两类握手在接口约定里分开写。

现状：行程间补偿的收敛过程只在内存里记（最多 500 条、换程序清空），不进记录；本节实现后由道次表取代。变量、缓冲深度与握手需与 NC 程序员约定（第 10 节第 0 期）。

倍率摘要（每道 / 每工序一行）

平均值、最低 / 最高值、非 100% 时间占比。记录页显示实际有效值，例如"拖板设定 2300 × 平均倍率 93% ≈ 2140 mm/min"。

判断标准：能否回答这五个问题

  1. 按什么设定磨的？——下发快照（含方案号）。
  2. 人做了哪些决定？——作业调整、换方案与原因。
  3. 实际怎么磨的？——道次表、倍率摘要、过程曲线。
  4. 结果如何？——测量结果、合格判定。
  5. 出过什么事？——报警与越界事件。

其余高频细节（每次拧倍率、每 100 ms 采样）只在运行时显示，不进记录。保留期按 recordRetentionDays（默认 730 天）。

7操作流程

新辊入厂

新建轧辊（或从已有辊复制）→填辊号、类型、几何→ 保存 →提示"建第一个方案"→辊形→工艺→设为当前

从已有辊复制：复制几何与当前方案（方案来源记为原辊），改辊号、按实测改尺寸；长度不同按第 4.5 节处理。

磨辊（高频）

待磨清单点辊→默认当前方案→核对页：磨前直径、磨削量、起点 Z、（可选）本次调整→✓ 确认下发→自动磨削→记录

改辊形或工艺

复制当前方案→修改→保存→设为当前

辊调去别的机架

历史方案里有对应用途的就设回当前；没有就新建（可从同用途的其他辊复制）。

中断、返磨

沿用现有做法：中断待续置顶，续磨先重新量磨前直径；不合格一键返磨，用同一方案新开作业。

已定决策
