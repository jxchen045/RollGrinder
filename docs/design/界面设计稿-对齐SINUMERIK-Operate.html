界面设计稿：对齐 SINUMERIK Operate 的操作习惯

操作工在这台机床上同时面对西门子 Operate 和本上位机。两边的"区域怎么切、横键竖键各管什么、数怎么输、危险动作怎么确认、提示在哪一行"如果一致，就不用学两套。本稿先整理 Operate（SINUMERIK ONE，含第二代触摸界面）的操作习惯，再据此重排本上位机的外壳、区域和每一页的软键，并把上一稿（触摸屏与按钮板方案）的内容合进来。

0结论

外壳照 Operate 分区顶上三行状态区（区域 + 方式 + 报警行 / 程序 / 通道状态），右上"功能键块"（区域菜单、返回上一级、帮助、键盘），底部上方一行对话行，横 8 竖 8 软键；宽屏可开左侧"侧屏"小部件。
横键选"看什么"，竖键做"做什么"这是 Operate 最核心的习惯，也是现在差得最远的一处：现在底部横键放的是保存、另存为这类动作。改为横键切视图、竖键放动作；"确认 / 取消"固定在竖键第 8 / 第 7 格。
区域按 Operate 重组机床（自动与手动合并，视图跟着 NC 方式走）、参数、程序、程序管理、诊断、调试，另加本机特有的"记录"，共 7 个区域，名称和顺序与 Operate 对得上。
编程像 ShopTurn程序编辑器的横键就是工序类别（磨削、测量、修整、倒角、辅助），按下后竖键列出具体工序，填完参数按"确认"插入。帮助图亮当前参数，和 Operate 的循环画面一样。

改动量约 6–7 周，建议分两期：第一期先做外壳、输入、确认（操作习惯的大头，约 3 周），第二期做区域重组与各页软键重排（约 3–4 周）。第 12 节列了 8 个需要一起定下来的问题。

调研的局限

这次的运行环境拦住了西门子支持站点的原文下载（手册 PDF 打不开），第 1 节的结论来自手册目录、摘要与公开资料，每条标了出处可信度。颜色、图标这类细节，最好以这台机床上 Operate 的实际画面为准——请拍几张照片或截图（机床区 AUTO / JOG、程序编辑器、程序管理器、报警列表），我对照改稿。

手册 西门子手册或其摘要里明确写的；推断 由手册描述与常见画面推断、需要在现场画面上核对的。

方面Operate 的做法依据
分区一屏由这些部分组成：当前操作区域与方式、报警 / 消息行、程序名、通道状态与程序控制、通道运行消息、实际值窗口（轴位置）、T/F/S 窗口、工作窗口（程序段显示等）、对话行（给操作者的补充提示），以及 8 个横向、8 个竖向软键。机床区的状态显示为三行。手册

横键与竖键每个横向菜单项对应一组竖向软键：横键选功能，竖键是这个功能下的操作。竖键不够时用 ">>" 翻到下一组、"<<" 回来；横键也可以有第二页。手册
返回上一级实体键"菜单返回"（^）回到上一层软键；触摸界面把它和"菜单选择"等放在屏幕上的"功能键块"里（第二代界面）。手册
确认参数画面、询问框的"确认 / 取消"放在竖向软键上，通常是最下面两格（取消在上、确认在下）。推断
输入输入框有提示；选项型的是"切换框"，按 SELECT 键就地换值（Shift 反向），不必打开；输入框里可以用 "=" 调计算器；Insert 在还没确认前可以撤销；每个画面可按 Help 看帮助。手册
帮助图每个循环画面配一张帮助图，当前参数在图上用颜色标出。ShopTurn / ShopMill 按工步编程，彩色帮助图贯穿始终。手册
虚拟键盘触摸面板用虚拟键盘输入：在输入框点一下放光标，再点一下弹出键盘；键盘可拖到屏幕任意位置；可在全键盘与只有数字块的小键盘之间切换，全键盘可切英文 / 当前语言。宽屏面板（OP 015 black）把字母数字键放在屏幕右侧，输入时不遮工作区。手册
手势单指竖向轻扫：列表滚动；双指竖扫：翻页；三指竖扫：到头 / 到尾；单指横扫：多列表格横向滚动；双指张开 / 捏合：图形放大 / 缩小；双指点：快捷菜单（复制、粘贴）。手册
侧屏宽屏多点触摸面板可开"侧屏"：界面左侧出现导航条，放小部件（实际值、零点偏移、报警等，收起时只剩标题行，竖扫翻动），也可以放键盘、机床控制面板。手册
状态图标通道状态有专门的符号：复位、运行、中断、进给未使能；主轴正转 / 反转 / 未使能 / 停止。报警行显示最新报警，"PLC"图标标出 PLC 报警，箭头表示还有多条，确认符号表示可以确认。手册
分辨率OP 015 black 为 15.6″ 1366×768 宽屏；OP 019 为 19″ 1280×1024；新版本在 FullHD 下有"三窗口"视图。界面要适配几种尺寸。手册 / 产品资料
视觉浅色为主，工作窗口白底，颜色只用在状态上（运行、报警、当前参数），软键灰底黑字、带少量图标。推断，待对照现场画面

西门子自己的工业界面设计体系 Siemens iX 提供"经典浅色 / 经典深色"主题与成套配色令牌，可以作为配色的参照（不是照抄 Operate 的像素）。

3设计规则（替代修改稿原则 1）

  1. 横键选视图，竖键做动作。按下的横键保持"按下"样子，竖键随之换成这个视图的动作。一个视图的动作超过 8 个时，竖键第 8 格是 ">> 更多"。
  2. 确认 / 取消固定位置。任何需要确认的事（插入工序、保存、删除、危险动作、下发）都在竖键第 8 格"确认"、第 7 格"取消"，并在对话行写出要确认的是什么。
  3. 导航不占软键。区域菜单、返回上一级、帮助、键盘在右上"功能键块"；接键盘时对应 F10（菜单选择）、Esc / F9（返回）等（见 4）。
  4. 一个对话行说所有"为什么"。参数说明、单位范围、输入错误、灰键原因、确认问题，都在软键条正上方这一行。
  5. 状态区在每个区域都一样。不论在哪一页，区域、方式、报警、程序、通道状态都在同一位置。
  6. 动与停归按钮板；屏幕跟着机床的方式走。方式在按钮板 / 机床控制面板上切，机床区的画面自动切过去。
  7. 触摸优先、键盘兼容（上一稿的尺寸、键盘、手势规则全部保留，见 7）。

5区域重组

区域栏（点 ☰ 或 F10，横键条换成区域）按 Operate 的名称与顺序排，本机特有的"记录"放在第 5 格：

横键区域对应 Operate装什么（从现在哪里来）
1⚙ 机床机床自动磨削页 + 手动页 + 对中（视图随 NC 方式切换）；作业向导从这里进
2▦ 参数参数（刀具、零点、设定数据）标定值（分组）、砂轮与修整、补偿设定、验收公差——相当于 Operate 里的刀具与设定数据
3✎ 程序程序（编辑器）当前打开的工艺程序或辊形的编辑器（现在的工艺程序页、辊形页）
4🗀 程序管理程序管理辊形库、工艺程序库、作业、轧辊台账、U 盘——现在散在各页的"库"都收到这里
5▤ 记录（本机特有）磨削记录、报表、日报月报（现在的记录页；台账挪去程序管理）
6⚠ 诊断诊断报警列表、报警日志、变量监视、改动记录、运行日志、快照与备份（现在的诊断页）
7⚒ 调试调试机床配置、标签映射、用户与权限、系统（语言、屏幕、触摸、键盘提示）——从诊断页和登录框挪过来
8区域栏的第 8 格：收起区域栏（与再点一次 ☰ 相同）

为什么合并自动与手动：Operate 里 JOG、AUTO 是"机床"区域的两种方式，操作工在控制面板上切方式、屏幕跟着换，不会去"找手动页"。本机的方式也在按钮板 / 控制面板上切，屏幕跟着切到"手动"或"自动"视图最顺手。

为什么把库集中到程序管理：Operate 里打开、复制、删除程序都在程序管理器，编辑器只管编辑。现在辊形页、工艺程序页各自带一个库浮层，操作路径不一样；集中之后"找东西去程序管理，改东西在程序区"。

6.4 参数

横键：标定 砂轮 修整 补偿 公差 换砂轮。"标定"按部件分组（阶段 3 已做），竖键：保存…、放弃改动、改动记录。"换砂轮"是阶段 1 的向导，每步配图，竖键：上一步、下一步、放弃…；最后一步竖键第 8 格"确认"。

6.5 记录

横键：记录 指标 曲线 日报 月报 报表；竖键：查询（日期段）、上一条、下一条、打印、导出。台账挪到程序管理。

6.6 诊断

横键：报警列表 报警日志 变量监视 改动记录 运行日志 连接 快照备份。与 Operate 的诊断区域同一套名字。"清除上位机报警"在报警列表的竖键上（不再叫"复位"）。

6.7 调试

横键：机床配置 标签映射 用户 系统 版本。机床配置、标签映射就是阶段 3 的编辑器，竖键：保存…、恢复上一版…、放弃改动、只看缺失、登记、试读；"系统"里放语言、屏幕（显示在哪块屏、缩放）、触摸（键盘自动弹出、快捷键提示、擦屏模式）。整个区域只有制造商能改（Q9）。

7输入、确认、手势

7.1 输入框

  • 点一下选中：格子高亮，工序简图上亮出这个量，对话行写说明、单位、范围（和 Operate 的循环画面一样）。
  • 再点一下（或点 ⌨）弹出键盘：默认是数字块，停靠在不遮住当前格的那一侧，可以拖动；"ABC"切全键盘，"中文"调系统输入法。
  • ↵ 输入确认并跳到下一格（Operate 的 Input 键）；"取消"恢复原值；超出范围不收，对话行说原因。

7.2 确认

凡是会改库、会动机床、会丢数据的事，统一用 Operate 式确认：对话行写问题，竖键第 7 格"取消"、第 8 格"确认"，4 秒不确认自动取消。替代现在的"同一个键按两下"和上一稿提的"按住确认"——确认键换了位置，误点两下不会触发，也和 Operate 一样。接键盘时回车 = 确认，Esc = 取消。

8视觉

  • 保持浅色。Operate 是浅色界面，现在的配色也是浅色，不做深色主题（车间照明下浅色更好读，也和旁边的 Operate 一致）。
  • 颜色只表示状态：绿 = 运行、开、到位；黄 = 中断、警告、未保存；红 = 报警、急停、错误；蓝 = 当前选中（按下的横键、选中的行）；灰 = 关、不可用；虚框 = 读不到。其余一律灰阶。
  • 软键：灰底黑字，按下的横键反白（蓝底白字）；"确认"绿底、需要确认的危险键红字红框；文字不超过两行、每行约 6 个汉字；有下一层的键末尾加 ">>"，返回上一层是 "<< 返回"（取代现在的 ▸ 与 «）。
  • 图标：区域、功能键块、通道状态用图标 + 文字；图标风格与 Operate 的区域图标接近（线性、单色）。图标具体样子等看了现场 Operate 画面再定。
  • 字号：正文 16–18 px、数值 20–24 px、大读数（实测直径）40 px 以上；等宽字体只用在数值与编号。
  • 配色令牌：参照 Siemens iX 的"经典浅色"主题整理一套令牌（背景层级、文字主次、状态色），替换现在散落的颜色值。

9与按钮板的分工（沿用上一稿）

  • 急停、复位、头架与砂轮的转停、循环启动在按钮板上；屏幕上不给这些键，只显示状态（状态区、侧屏、手动视图）。哪些在按钮板上由 machine.json 的 panelActions 登记。
  • 方式（JOG / AUTO）在按钮板或机床控制面板上切，机床区视图自动跟着切（需要 tagmap 里的 machine.operatingMode，阶段 3 已加）。
  • 急停时状态区第 1 行整行变红"急停中——解除后在按钮板上按复位"，所有命令键灰掉，点灰键对话行说原因。

10不照搬的地方

  • 不做 G 代码编辑、MDA、程序段显示。本上位机下发的是参数，不是 NC 程序；Operate 里这些功能留在 Operate。
  • 不模仿 Operate 的像素。布局、交互规则对齐；画面仍是本软件自己的，免得被误认为是西门子的产品界面。
  • 工序简图保留本机自己的图（磨削、测量、修整、倒角），风格向 Operate 帮助图靠（线条图、当前量彩色）。
  • 作业向导保留：Operate 没有"选辊 + 辊形 + 程序"这一步，这是本机的核心流程，放在机床区的"作业"视图里。
  • 记录区保留：Operate 没有磨削记录与报表。
