MK84160 轧辊磨床 · SINUMERIK ONE · RGX 上位机 · 设计稿第 4 版 2026-09-29 · 待讨论，源代码未改

界面设计稿：以轧辊磨削为核心，操作习惯对齐 Operate

这台机床磨的是轧辊，上位机存在的理由是三件事：把辊形编对、把辊磨到辊形上、把磨得怎么样看清楚并记下来。界面为这三件事服务。SINUMERIK Operate 只借它的外壳和操作习惯——软键怎么用、怎么确认、提示写在哪、颜色表示什么——不借它为铣床和加工中心设计的画面内容。

0纠偏与结论

第 3 版偏了

第 3 版照着铣床手册排画面，把轧辊磨削的核心内容挤掉了：

  • 自动页主次颠倒：主角成了"实际值 + T,F,S"。误差曲线被挤到一个可选开关里；公差带、RMS、参数矩阵、实测直径大字、补偿状态都没有位置了。
  • 辊形编辑只剩一段文字：段表、预览曲线、当前段高亮、段界、点表与四种插值、对照线、对称编辑、边编边校验，这些已经做好、测过的功能一样都没画。
  • 工艺程序改成了列表：工序简图和参数要"打开"才能看到。还提议取消保存键，这和第一轮测试定下的保存语义冲突。
  • 磨削记录没画：4 条曲线和 12 项指标都不在稿子里。
  • 加了与磨辊无关的东西：程序控制、图纸 PDF、刀具式寿命表。

第 4 版纠正如下：

  • 以现在软件已有的轧辊磨削功能为底，逐项列清（第 1 节），每一项都在新画面里有位置、有样机（第 5 节）。
  • Operate 只管外壳和操作习惯（第 2 节）。
  • 第 3 版加进来的、与磨辊无关的东西都撤掉（见第 2 节"不借"）。
曲线常在自动页的中心是误差曲线（公差带、RMS、砂轮当前位置）；辊形编辑的中心是辊形预览；记录页的中心是磨前 / 磨后曲线。曲线不藏在开关或第二层后面。
功能一项不少第 1 节列了 60 多项现有功能，逐项标出新位置。新增的只有三样：砂轮位置竖线、公差带填色、曲线手势缩放。
外壳照 Operate
  • 左栏快捷入口：机床、辊形、工艺、砂轮、库、记录、诊断。
  • 标题行兼报警行，机床区有程序路径条和通道行，横键上方一行对话行。
  • 竖键第 7 / 8 格是取消 / 确认。
  • 青色只表示"现在在这里"。
改动量变小画面的内容和布局基本沿用现在的；改的是外壳、软键位置和确认方式。约 5 周，比第 3 版少 2.5 周。

2从 Operate 借什么、不借什么

借理由
外壳：左栏快捷入口（图标 + 文字）、标题行兼报警行、右上区域 / 方式方块、机床区的程序路径条和通道行、功能键块、对话行操作工在同一台机床上看 Operate，位置一致就不用找
竖键第 7 / 8 格红色"✕ 取消"、绿色"✓ 确认"；子画面第 8 格"« 返回"；有下一层的键带"▸"替代现在的"按两下"，更不容易误触；位置和 Operate 一致
横键是功能组，按下后竖键给出这个功能的操作；自动页的竖键是"看哪条曲线"Operate 自动方式的竖键就是显示开关；这里正好用来选曲线
颜色：青色 #0199C8 只表示当前窗口、按下的键、当前格；浅灰蓝窗口、灰标题条、深色左栏和 ONE 一致；把颜色留给状态和曲线
输入：点一下选中、再点出数字键盘；当前格青底；切换格；单位写在格子后面触摸屏上好用，和 Operate 的循环画面一致
黄色帮助模式、工序简图上的当前参数用橙色和 ShopTurn 的帮助图一致
手势：长按打开、双指缩放曲线ONE 手册 p.23
不借理由
以"实际值 + T,F,S"为主的机床画面磨辊看的是辊形和误差，不是刀具和轴坐标；X、Z、转速放在状态带里就够了
ShopMill 的"列表 → 打开 → 参数"两层编辑辊形和工序必须边编边看曲线和简图；现在的"表 + 图 + 参数同屏"更适合，保留
"确认就写入、没有保存键"第一轮测试定下的是"保存只更新当前条目、另存为必须改名、有错不能保存"，保留
程序控制、图纸 PDF、刀具式寿命表、显示管理器与磨辊的核心任务无关，不做
G 代码编辑、MDA、NC 仿真上位机下发的是参数，不是 NC 程序

3设计规则

  1. 轧辊磨削优先。每个画面先问"这里要看清的是哪条曲线、哪个数"，它占最大的位置；外壳和软键为它让路。
  2. 曲线常在。自动页的误差曲线、辊形编辑的预览、工艺程序的工序简图、记录页的磨前 / 磨后曲线，在各自的画面上始终可见，不需要额外按键才出现。
  3. 表、图、参数同屏。编辑辊形和工序时，改参数的同时看到图的变化；不把它们拆成两层。
  4. 横键是功能组，竖键是这一组里的操作。竖键第 8 格是"✓ 确认"、"« 返回"或"≡▸ 翻页"之一；第 7 格需要时是"✕ 取消"。
  5. 边编边校验，保存语义不变。有错不能保存、不能用于作业、不能下发；保存只更新当前条目；另存为必须改名。
  6. 动与停归按钮板。屏幕上不放启动、停止、复位、主轴转停；机床区画面跟着 NC 方式切换。
  7. 上位机只编辑、显示、记录。参数下发以后，上位机不参与实时控制；上位机退出，这支辊照样磨完。

4外壳与区域

外壳沿用第 3 版（样机见 5.1）：

  • 左栏是快捷入口，每项图标加文字；右上是区域 / 方式方块，再下面是功能键块（撤销 / 重做、键盘 / 计算器、帮助 / 截屏）。
  • 标题行兼报警行；机床区有灰色程序路径条和深灰通道行。
  • 横键上方一行对话行，横 8 竖 8 软键。

区域按轧辊磨床的工作重新排，正好 8 个，占满区域菜单的 8 个横键：

  • 表单：左边标签、右边白色数值格，数值右对齐，单位写在格子后面；只读量写灰字。当前格青底，简图上对应的量是橙色，对话行写说明、单位、范围。

8操作流程（以磨辊为主线）

红框表示在按钮板上操作，其余都在触摸屏上。

左栏 辊形→横键 新建→填名称、设计长度→竖键 插入段 ▸ 锥度→插入段 ▸ 凸度→插入段 ▸ 锥度→逐段填参数，看预览→校验通过→横键 保存

F3 开磨一支辊

机床 · 横键 作业→① 选轧辊→② 选辊形→③ 选程序→④ 程序步骤→⑤ 核对（看辊形套在辊身上）→✓ 确认下发→按钮板 AUTO + 循环启动→自动磨削画面

F4 磨削中盯误差、改下一道

自动磨削：看误差曲线和公差带→竖键 切到圆度 / 磨削电流对照→参数矩阵点下一道的格→改值（格子标红）→✓ 下发改动

F5 看补偿是否收敛

自动磨削 · 横键 补偿→看修正量曲线逐版下降→看各次测量 RMS / 峰谷→（制造商）调增益、限幅→✓ 保存补偿设定→« 返回

F6 磨后判定、补磨

磨后测量完成→误差曲线有超差段（加粗红线）→横键 工序跳转 → 选精磨…→✓ 确认→循环启动

F7 查一支辊的磨削记录

左栏 记录→点选这支辊→看磨前 / 磨后辊形和 12 项指标→竖键 误差 / 圆度 / 补偿收敛→打印 / 导出
