第一轮测试后修掉的问题，复测时请重点看这几处（详见《第一轮测试修改稿》）：

  • 启动后不加工（3①）：程序以"开始"打头时，下发的通用进给取第一道真正走拖板的工序；仿真机床按每道工序自己的进给走，"开始 / 结束"这类工序原地停几秒。一支辊要按预计时间磨，不会再 3 秒"磨完"。磨得比预计快得多（不到四分之一）时，报警条会出黄色警告。
  • 库里同名（辊形 1②③、程序同样）："另存为"先弹出命名框，默认"原名-副本"；名字在库里已经有了，框里给出"覆盖那一条 / 改名 / 取消"。按"保存"时改的名字撞上别的条目，也走这个框。
  • 辊形编辑（1①⑦⑧⑨）：曲线段可以删到一段不剩（空辊形不能保存）；补了"下移"；去掉功能条上重复的"新建曲线段"；新增"设计长度"一栏；每改一次就校验，问题逐条列在预览上方，出错的段和参数格标红，有错时"保存""另存为"变灰。
  • 工序编程（2④⑥）：每道工序后面加了 ▲ ▼（上移、下移）；左栏加"校验"按钮；保存、另存为之前自动校验，不过不存，原因列在右栏轧辊数据下方。

1测试前须知

本轮测什么，不测什么

测不测（等真机联调）
  • 操作流程顺不顺，和现场加工顺序是否一致
  • 界面上的叫法、单位是否和现场一致
  • 每一页信息够不够、多不多、放的位置对不对
  • 按键的位置、分组、哪些要二次确认
  • 参数默认值、报表栏目与格式
  • 磨削精度、测量数值（本轮全部由仿真产生）
  • 与 NC / PLC 的通讯（OPC UA）
  • PLC 联锁与安全回路
  • 真实打印机的打印效果

上位机在这台机床上的角色

请在开始前向甲方说明这一点，很多界面设计都由它决定：

  • 上位机只做编辑、显示与记录，不参与实时控制。参数下发之后，磨削由 NC 执行。上位机被关掉或死机，当前这支辊照样磨完。
  • 界面上的"启动""暂停"、手动页的各个动作，都只是向 PLC 发请求。能不能动，由 PLC 的联锁决定。
  • 自动循环运行期间，工序编程页和辊形编辑页自动变成只读，"下发 NC"键变灰，防止改动正在磨的这支辊。
  • 上位机没有"按住才动"的点动。点动归机床操作面板和手轮。
仿真机床与真机的差别
  • 下发参数后仿真机床立即开始"磨削"，不等循环启动。真机要等操作工按启动。
  • 直径、电流、圆度、测头读数等都是模拟生成的，只看流程和显示方式，不评价数值。报表里有些项显示"--"，表示没有量到（不是 0）。
  • 仿真机床接受所有手动命令，不会因为机构状态拒绝。真机上 PLC 可能拒绝。

屏幕与操作方式

  • 界面按 1920×1080 设计。建议接一台 1920×1080 显示器或投影，Windows 缩放设为 100%。笔记本开 125% 或 150% 缩放时界面会挤。
  • 本轮用鼠标、触摸屏都可以。键盘 F1–F8 对应屏幕底部 8 个软键，Ctrl+1…7 直接切页。
  • 机床工控机是触摸屏还是带实体软键的面板，目前还没确认（见第 7 节问题 1）。请甲方在测试中留意：如果现场只有按键、没有触摸，哪些操作会不方便。

2环境准备与启动

需要准备

  • Windows 10 或 11 电脑，装有 .NET 8 或更高的 SDK（装了 Visual Studio 即已包含）。
  • 最新源码：用 bundle 更新，或把源码 zip 解压到空文件夹。
  • 如果要看自动打印的报表：把 Windows 默认打印机设为"Microsoft Print to PDF"，自动打印时会弹出保存框，存成 PDF 看版式。

启动（推荐：双击演示脚本）

在源码目录里双击 scripts\start-demo.cmd。脚本会先编译最新源码（第一次约 1 分钟，之后几秒），然后以仿真机床、5 倍速启动上位机。演示数据放在源码目录下的 demo 文件夹，不影响其他数据。

要换模式，在命令行里带一个参数运行：

命令作用
start-demo.cmd仿真机床，5 倍速。按 4 道工序的程序估算，一支辊约 1 分钟磨完
start-demo.cmd 20仿真机床，20 倍速（1–100 任选）。1 是正常节奏，一支辊约 5 分钟。想让甲方看清运行过程就调低，想快速走完流程就调高
start-demo.cmd offline离线编程模式（场景 K）：只能编程、编辑辊形、查记录、改设置，自动磨削、手动、诊断三页变灰
start-demo.cmd reset先清空演示数据再启动（见下面"恢复到干净状态"）
在 PowerShell 里运行

PowerShell 不会直接运行当前目录里的程序或脚本，前面要加 .\，否则会报"无法将……项识别为 cmdlet、函数、脚本文件或可运行程序的名称"：

cd D:\Projects\RollGrinder\scripts
.\start-demo.cmd 5

在"命令提示符"（cmd）里不用加 .\。

其他启动方式

  • 直接运行程序（已经编译过时）： 
    cd D:\Projects\RollGrinder\src\RollGrinder.App\bin\Release\net8.0-windows
.\RollGrinder.App.exe --gateway sim --sim-speed 5 --config D:\Projects\RollGrinder\demo\config --data D:\Projects\RollGrinder\demo\data
    参数含义：--gateway sim 连仿真机床；--sim-speed 仿真倍速；--config / --data 配置与数据库放到演示目录（不存在会自动建好）；把 --gateway sim --sim-speed 5 换成 --offline 就是离线编程模式。
  • Visual Studio：打开 RollGrinder.sln，启动项目选 RollGrinder.App，启动下拉选"仿真机床 (推荐)"，按 F5。这种方式是 1 倍速，数据放在程序目录下，和演示脚本的数据不是同一份。

恢复到干净状态

关掉上位机，运行 start-demo.cmd reset，或者手动删掉源码目录下的 demo 文件夹再启动。账号、程序库、辊形库、磨削记录全部清空，等于新装的软件。

第一次登录

  1. 启动后整屏被登录框挡住，没登录什么都点不了。
  2. 用户名选 admin（出厂自带的制造商账号），密码留空，按"确定"。提示"这个账号还没设过密码，先设一个"，出现"新密码""确认新密码"两栏。
  3. 两栏填同一个密码（记在封面的"演示密码"栏），按"确定"。登录框消失，进入主页"自动磨削"。顶栏右侧显示"制造商 admin"。

5测试场景

场景 A 到 I 按一支辊的真实加工顺序排列，建议按顺序做。每个场景后面有"请重点看"的要点和意见栏，可以直接写在打印稿上。场景 J、K 视时间和参加人员决定。

B 编辑辊形并存入辊形库

约 10 分钟参加：工艺人员

页面布局：左边是辊形名、设计长度和"曲线段（可叠加）"列表，中上是校验结果和"辊形预览（直径量）"，下面是所选曲线段的参数。辊形类型有四种：圆柱、凸度、锥度、CVC。

现在的辊形仍是逐段叠加：主辊形铺满全长，端部锥度等再叠在上面，两段重叠处偏差相加。"起点 Z + 段长、自动首尾相接"的新方式在阶段 1 做。

  1. 按 Ctrl+3 进辊形编辑页。
  2. "设计长度"填 2000（mm）。预览横轴变成 0–2000 mm，原来那段圆柱没铺满，校验结果里马上出现红字"…没有曲线段覆盖（断开）"。
  3. 选中那段圆柱，按左栏"删除"。可以删到一段不剩；校验结果写"还没有曲线段"，F1保存 和 F2另存为 变灰。
  4. 在类型下拉里选"凸度"，按"插入"。第一段自动铺满 0–2000 mm，参数区出现"凸度（直径量）"，校验结果变成"校验通过"。
  5. 凸度填 300（µm，直径量）。预览曲线随参数实时变化，光标一直留在输入框里。
  6. 再插一段"锥度"，区间改成 1850–2000，锥度填 50 µm。校验结果里多一行灰字提示"第 2 段叠加在第 1 段上"，这是正常用法，不影响保存。
  7. 故意把区间终点改成 2500。立刻出现红字"超出设计长度"，这一段行尾出现红标，保存键变灰。改回 2000 恢复。再试一下凸度填 5000：参数格下面标红说明越界。
  8. 试一下"上移""下移""删除"。选中跟着挪动的那一段走，连按几次能一直挪。
  9. 在"辊形名"填 工作辊-凸度300，按 F2另存为。弹出命名框，名字可以再改，回车或"确定"存进库；Esc 或"取消"不存。报警条提示"辊形已存入库"。
  10. 再按一次 F2另存为，框里默认是"工作辊-凸度300-副本"；把名字改回 工作辊-凸度300 再确定。框里说明库里已有同名的，给出"覆盖那一条"，也可以改名或取消。
  11. 按 F6辊形库。列表里只有一条"工作辊-凸度300"（辊形名、主曲线、段数、修改时间），可以打开、删除、关闭。
  12. （可选）F4生成点列 把辊形导出成点表（CSV）；F3点表导入 导入一份对照点列，看"与对照线最大相差 x µm"。

请重点看

  • 四种辊形类型够不够；现场常用的辊形有没有缺
  • 凸度、锥度按直径量、µm输入是否符合现场习惯（有的现场习惯按半径量或 mm）
  • "多段叠加"的编辑方式是否好理解
  • 辊形命名规则；是否需要预置现场常用辊形
  • 点表导入 / 导出的文件格式是否和现场已有资料对得上

C 工序编程

约 15 分钟参加：工艺、操作人员

页面布局：左栏是工序序列（工序类型选择、"添加工序""新建作业"、预计总磨削时间）。右边一整栏可以上下滚动，从上到下依次是：轧辊数据（作业号、辊件号、辊身长度、公称直径、辊形来源，标题右侧显示下发状态）、辊形参数、所选工序的工艺参数、补偿设置、程序步骤。

  1. 按 Ctrl+2 进工序编程页，按 新建作业。生成新的作业号（J 开头），工序清空。
  2. 填辊件号 R-2026-001、辊身长度 2000、公称直径 600。
  3. 辊形有两种来源：默认"本页现编"，直接在本页选辊形类型、填辊形参数；或者按 F3选择辊形，从辊形库里选场景 B 存的辊形，按"选用"。"辊形来源"显示库里的辊形名。按"改回现编"可以恢复本页现编。
  4. 在工序类型下拉里选工序，按 添加工序。下拉按 5 个工序槽分组（粗磨、半精磨、精磨、超精磨、倒角或修整砂轮），另有不占槽的工序（测量、圆度测量、暂停等）。本机未配置的工序显示"（未配置）"。
    建议顺序：测量 → 粗磨 → 精磨 → 测量 → 圆度测量。左边工序序列按顺序列出，每道后面有预计时长、▲ ▼（上移、下移）和"删除"。
  5. 用 ▲ ▼ 调一下工序顺序。序号跟着重排。
  6. 在左栏点选"粗磨"，右栏的工序参数区显示它的工艺参数：拖板速度、周期进给或连续进给、磨削道次、光磨道次、砂轮线速度、头架转速、变速设置等。按现场习惯改几项。填错或超出机床能力的格子当场标出，并说明原因。
  7. 看"预计总磨削时间"随工序和参数变化。

  9. 看"补偿设置（制造商权限）"：行程间增益、空间滤波窗口、单次修正限幅、单刀切深上限、辊形公差。这里只显示，不在本页修改。
  10. 按 F4轧辊数据：填启磨点坐标、曲线长度、曲线允许误差、轧辊净重、头架端箱重、尾架端箱重，按"保存轧辊数据"。吊装总重自动算出；缺任何一项显示"--"。第 8 键显示"返回 工序编程"。

页面布局：
