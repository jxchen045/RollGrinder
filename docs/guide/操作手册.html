MK84160 数控轧辊磨床 · 上位机 RGX

RGX 上位机操作手册

给操作工、工艺员、设备管理员用：从登记一支辊、画辊形、编工艺，到下发、监视磨削、查记录打报表。按键名称和提示文字都取自软件本身。

1概述

上位机在这台机床上做什么

最高原则

上位机被强制关闭时，正在磨的这支辊照样磨完。参数下发之后，上位机只做编辑、显示与记录，不参与实时控制；磨削由 NC 执行。

  • 屏幕上的"循环启动""暂停"和手动页的各个动作，都只是向 PLC 发请求，能不能动由 PLC 联锁决定。
  • 停止类操作（急停、进给保持、复位、回参考点、头架正反转）在机床按钮板上，不依赖上位机。
  • 上位机没有"按住才动"的点动；点动归机床操作面板和手轮。
  • 自动循环运行期间，辊形、工艺程序、作业、参数这几页自动变成只读，防止改到正在磨的这支辊。

四样东西

东西现实里是一句话谁维护
轧辊（台账）一根实物辊多大、正常怎么磨（计划）、磨过几次、还能磨多少班长 / 操作工
辊形设计图纸磨成什么形状、公差多少工艺员
工艺程序工艺卡用哪些工序、进给、速度、余量去磨工艺员
作业工单这一支辊这一次：磨多少、核对结果；下发时存快照操作工

辊形和工艺程序可以给很多支辊共用；每支辊在台账里记着"正常按哪条辊形、哪支程序磨"。每次磨削开一份作业，把三者合在一起核对后下发。

两种屏幕

19″ 1920×1080 用标准档，15″ 1366×768 用紧凑档，按屏幕自动选；也可以在 config/hmi.json 里写 "layout": "standard" 或 "compact" 固定。两档的画面结构、按键位置完全一样，紧凑档只是字小一号。Windows 显示缩放请设 100%。

夜班嫌屏幕刺眼，可以在 config/hmi.json 里写 "theme": "dark" 换深色，重启生效；颜色的含义（红 = 当前工序 / 报警、绿 = 正常、黄 = 下一工序）不变。

2启动、登录与关闭

启动

  • 工控机开机后上位机自动启动，无边框全屏（config/hmi.json 里 "fullScreen": true）。已经在运行时再启动一次，会提示"已经在运行"并退出。
  • 办公室电脑上编程用离线模式（--offline 启动，或演示脚本 start-demo.cmd offline）：标题行写"离线 · 编程模式"，能编辑辊形、工艺、台账、查记录；自动磨削、手动、诊断这些要连机床的页是灰的，作业不能下发。

登录

  1. 启动后登录框挡住整屏，没登录什么都点不了。
  2. 填用户名（或按框下面"已有用户"里自己的名字），填密码，按"确定"。
  3. 第一次登录、还没设过密码的账号：提示"这个账号还没设过密码，先设一个"，两栏填同一个密码再按"确定"。操作者用 4–8 位数字 PIN，管理员、制造商用密码。
  4. 标题行显示角色和名字，例如"操作者 李工"。

交班时点标题行上的名字 → 签退，登录框重新挡住整屏。新机器出厂只有一个制造商账号 admin，第一次登录时设密码，然后在"用户管理"里建各人的账号（第 16 节）。

关闭

先保存正在编辑的东西，再按 Alt+F4。正在磨的辊不受影响（最高原则）。磨完时上位机没开着，这条磨削记录不会自动收尾，开机后到记录页按 标记完成… 补上（第 13 节）。

4参数在哪里设

每个数只在一个地方能改。别的页要显示它，就只读显示并写明来源，例如"取自台账：辊身 2000 mm"。

在哪里设设什么不在这里设
轧辊台账辊号、类型、材质、用途、辊身长度、公称直径、报废直径、重量；当前直径（磨完自动写回）；计划：目标辊形、磨削程序（可后补）启磨点、曲线长度、曲线允许误差
辊形分段结构（段类型、段长、端部锥度长度）、形状参数（凸度、锥度量、CVC 系数、点表）、公差；参考轧辊（设计长度从它带入，只读）不手填长度、不收直径
工艺程序工序顺序、进给、速度、道次、标准余量、余量分配、倒角、程序步骤默认开关、适用类型 / 材质不收长度、直径（估时临时填一个辊号，不保存）
砂轮砂轮直径、宽度、修整参数—
作业（每次）磨前直径（默认台账当前直径，可实测）、本次磨削量（→ 目标直径）、磨削起点 Z（"取当前 Z"示教）、这一次的程序步骤开关—
机床配置（制造商）机床能力、长度容差、电流上限、定位坐标等—

下发时怎么合在一起

"生成程序"发生在作业下发那一刻：

下发给 NC 的量来源
辊半径作业的磨前直径
辊身长度台账
辊形点列辊形，按这支辊的辊身长度套好后生成
各工序参数工艺程序；粗磨余量按"本次磨削量"自动调整
报废直径台账（NC 支持时，NC 磨前测量后自己判断）
磨削起点 Z作业（标签映射里登记了 job.grindStartZMm 时）

辊形怎么套到长度不同的辊上（2% 规则）

  • 两端紧贴端面的锥度段保持绝对长度不变，中间段伸缩铺满辊身。凸度、圆柱这类中间段，长度差多少都能套。
  • 中间段是 CVC 或点表时，形状随长度走：长度差超过 2%（machine.json 的 lengthTolerancePercent）就拦住。
  • 曲线不铺满整根辊身（两端留一段不修形）时，留出的那段在辊形里写成一段圆柱，段长写在辊形里，仍然铺满整条辊身。

5一支辊的完整流程

  1. 登记轧辊（第 6 节）：轧辊区 › 新登记轧辊，填辊号、类型、尺寸。计划可以先空着。
  2. 画辊形（第 7 节，已有合适的就跳过）：辊形区，参考轧辊填这支辊的辊号，长度自动带入；分段编好，存进辊形库。
  3. 编工艺（第 8 节，已有合适的就跳过）：工艺区，插入工序、填参数、标准余量，存进程序库。
  4. 定计划：回到轧辊台账，编辑这支辊，选辊形、选程序。以后每次磨都默认用它们。
  5. 下作业（第 9 节）：机床区 › 作业，待磨清单里点这支辊 → 核对页。填磨前直径、本次磨削量，示教磨削起点，看核对结果，按 ✓ 确认下发。
  6. 磨削（第 10 节）：下发后自动切到自动磨削页；按按钮板上的循环启动。监视进度、曲线、直径和余量。
  7. 磨完：结果横幅写"✓ 合格"或"✗ 不合格"；记录自动收尾，台账当前直径自动写回；勾了打印的自动出报表。不合格的按 返磨…。
  8. 查记录、出报表（第 13 节）。

同一支辊以后再磨，只需第 5 步起。

左栏 ◍ 轧辊（Ctrl+2）。一支辊一行：辊号、类型、用途、直径、当前直径、剩余可磨量、计划、最近一次磨削。选中一行，下面是它的卡片和磨削履历。

登记一支新辊

  1. 按 新登记轧辊。也可以在作业页待磨清单的搜索框里输入辊号后按 新登记轧辊，辊号自动带过来。
  2. 填辊号；按 选类型 ▸（工作辊 / 支承辊）、选用途 ▸（从已有用途里选，例如"F3 上辊"；没有就 新用途…）。
  3. 填辊身长度、公称直径、当前直径（旧辊；新辊可空，默认用公称直径）、报废直径、材质、轧辊净重。
  4. 计划（目标辊形、磨削程序）可以现在 选辊形… 选程序…，也可以先空着——辊形要按一支已登记的辊画，所以新机型第一支辊通常先登记尺寸、计划后补。
  5. 按 ✓ 保存。尺寸超出机床能磨的范围、辊号重复、报废直径不小于公称直径、选的辊形长度与辊身差得太多（2% 规则）、程序适用类型不符，都会列出原因、不存。

批量改计划

凸度随轧制计划换轮时：按 多选 → 按用途 ▸ 选"F3 上辊" → 全选 → 改计划…，选新辊形 / 程序和原因，下面逐支列出能不能改（例如长度不符的不改）→ ✓ 改 n 支。每支辊的改动都进改动记录。

导入、导出

横键 导入… 读 CSV（先 导出模板… 拿到格式）。导入前逐行预览"新增 / 更新 / 错误"，可 只看错误；有错的行要改好再导，不会部分悄悄导入。导出… 把台账存成 CSV。

7辊形

左栏 ⌒ 辊形（Ctrl+3）。左栏是辊形名、参考轧辊、设计长度、公差、"对称编辑"开关和曲线段表；右边从上到下是校验结果、辊形预览（横轴整根辊身，纵轴直径量 µm）、所选段的参数。改辊形要管理员权限。

坐标与分段

  • Z 从头架侧辊身端面起算，向尾架为正。只有第一段填起点 Z，其余各段只填长度 L，首尾自动相接，不会重叠或断开。
  • 曲线类型：圆柱、凸度、锥度、CVC、点表，可以任意组合，例如"锥度 + 凸度 + 锥度"。
  • 锥度按"端部减薄量"填：正数就是端面比相邻段低多少，自动朝向所在一端的端面。
  • 相邻两段在交界处差超过 1 µm 报"跳变，接不上"。凸度、锥度、CVC 都按直径量 µm 输入。

编一条新辊形

  1. 在辊形库按 新建，或在辊形页从空白开始。
  2. 参考轧辊填一个台账里有的辊号。设计长度自动带入（只读），下面写"取自台账：辊身 2000 mm"。没填或台账里没有这支辊，不能保存。
  3. 勾"对称编辑"可以只编头架半边，尾架半边镜像生成（CVC 本身不对称，对称时不能插）。
  4. 竖键 插入段 ▸ 选类型，填段长和形状参数；用 删除段 上移 下移 复制段 改类型 ▸ 调整。点表段用 加点 删点 和 插值方式 ▸（折线、三次样条、保形三次、平滑样条；平滑样条首末两点钉住）。
  5. 两端要留一段不修形时，插一段圆柱。各段合计必须正好等于设计长度，超出或不足都报错。
  6. 填公差（直径量 µm，合格判定用它）。
  7. 填辊形名，按 另存为… 存进库。有错时保存键是灰的，错误逐条列在预览上方，出错的段标红。

库里已有的辊形

  • 横键 辊形库：左边列表、右边曲线预览。竖键 打开（或长按一行）、新建、复制…、重命名…、删除…、停用…、版本记录。横键 对比 把现在这一版和上一版逐项列出（只看不同 / 全部），辊形库还叠出两条曲线；在版本记录里选一版按 与现在这版对比。
  • 方案列表的竖键 对比：选中的方案和这支辊的当前方案比（选中的就是当前时，和最近用过的另一个比），辊形、工序参数、可调范围逐项列出，右边两条辊形以辊身中心对齐叠图。
  • 被轧辊计划引用的辊形，保存时先列出"有 n 支辊在用"，二选一：更新（这些辊下次起按新版磨）或另存为新的。已经下发的作业用的是快照，不受影响。每保存一次版本号 +1，旧版本只读留档，可 另存为新…。
  • 被引用的辊形不能删，只能停用；停用后登记、换辊形的列表里不再出现。
  • 没记参考轧辊的老条目、导入的条目，按存着的设计长度用（写"未记参考轧辊：按存的设计长度"）；填上辊号就改按那支辊。

其他横键

点表导入 读 CSV（每行"Z mm, 直径偏差 µm"）：选中的是点表段就换掉它的点，否则在选中段后面插一段点表。生成点列 把合成辊形导出成 CSV。导入对照线 只叠一条线对照，不改辊形。校验 和保存前同一套检查。辊形库横键 导入… 导出… 全部导出… 用 U 盘交换（.rgxlib，同名自动加"(2)"）。

8工艺程序

左栏 ≡ 工艺（Ctrl+4）。工艺程序是可复用的模板：一串工序和它们的参数，加上程序步骤的默认开关。它不含辊号、辊形、长度、直径，那些在作业里合进来。改程序要管理员权限。

编一支程序

  1. 横键 新建程序…。序列里只有"开始""结束"两道，固定在首尾，不能删、不能挪。
  2. 竖键 插入工序 ▸ 选类别：磨削 ▸（粗磨、半精磨、精磨、光磨、短行程、抛光）、测量 ▸（测量、圆度测量、涡流探伤）、砂轮修整、倒角、辅助动作、暂停。插在选中那道之后。本机没装的工序键是灰的。
  3. 选中一道工序，右边显示它的简图和参数：拖板速度、周期进给或连续进给、磨削量、磨削道次、光磨道次、砂轮线速度、头架转速、折返时间、在线测量、变速（模式 / 幅度 / 周期转数）等。光标在哪一格，简图上对应的量加粗变色，下面一行写说明、单位、允许范围。
  4. 辅助动作：选动作（切削液、中心架、尾架锁紧、测量臂……，在 machine.json 里登记）和开 / 关，NC 程序执行。
  5. 程序卡填标准余量（直径量）。按 余量分配 把去量的工序按比例分好，合计正好等于标准余量。作业里实际磨削量和它不同时，差额全部由粗磨吸收。
  6. 横键 适用类型 ▸（工作辊 / 支承辊）和程序卡的适用材质：作业里类型不符拦，材质不符只提示。
  7. 程序步骤（轧辊磨前测量、测量安装误差、轴线前馈补偿、U1 轴自动调平、砂轮自动趋近、允许在线测量、轧辊磨后测量、涡流探伤、打印磨前数据、打印磨后数据）：这里存默认值，作业里每次还能改。
  8. 想看预计磨削时间：在"估时用轧辊"里填一个台账辊号，按那支辊的尺寸算每道和总时长。这一格不存进程序。
  9. 填程序名，按 另存为…。保存前自动校验（参数范围、机床能力、至少一道走拖板），有错不存。

其他竖键：删除 上移 下移 复制 默认值（这一道回到默认参数）。工艺区的提示（"各道磨削量合计与总余量对不上""第 N 道磨完之后没有测量""后面一道磨削量比前面更粗的一道还大"）只提醒，不挡保存。程序库与辊形库用法相同，被引用的程序同样走"更新 / 另存为新的"。

9作业：核对与下发

机床区横键 作业（JOG 时 F8，AUTO 时 F6）。作业 = 这一支辊这一次磨：按台账计划，填磨多少，核对，下发。

待磨清单

  • 进作业页先看到待磨清单：中断待续和不合格待返磨的辊置顶，其余在用的辊按最近下线排。
  • 上面的输入框按辊号尾号模糊匹配；扫码枪当键盘用也行。
  • 竖键：下作业 ▸（中断的是 续磨 ▸、待返磨的是 返磨 ▸）、新登记轧辊、结束中断…、到轧辊台账。

核对页

选中一支辊按 下作业 ▸，进一页核对：

  1. 计划与这一次：台账计划的辊形、程序，以及这一次用的。没有计划的辊写"这支辊还没有计划：用'换辊形… / 换程序…'选"。
  2. 磨前直径：默认台账的当前直径，现场实测了就改成实测值（改了就算实测）。中断后续磨必须重新量。
  3. 本次磨削量（直径量 mm）：默认程序标准余量。目标直径 = 磨前直径 − 本次磨削量，自动算出、只读；下面写"最多可磨 x mm（到报废直径）"。
  4. 磨削起点 Z（NC 要这个数时才有这一行）：砂轮对到辊身头架侧端面，按 取当前 Z，把拖板现在的 Z 记下来；也可以手输。默认带这支辊上一次的值，旁边写"本次示教 / 沿用上次 / 未示教"。装夹动过一定要重新示教。
  5. 本次取舍：程序步骤开关，只列这支程序、这台机床用得上的；默认值来自程序，这一次可以改，改过的标出。
  6. 核对结果：逐项列出（附录 C），红色"不通过"拦住下发，橙色"提示"只是让人看见。
  7. 磨成什么样：辊形按 2% 规则套在这支辊上的曲线，以及各道工序和按这支辊算的预计时间。
  8. 全部没有红色时按 ✓ 确认下发。参数写进 NC，上位机请求 AUTO，自动切到自动磨削页。核对有拦的时候 ✓ 是灰的，按了对话行说哪一项没过。

这一次不按计划

  • 竖键 换辊形… / 换程序…：列出合适的（显示全部 看所有），选一条，再选：
    • ✓ 仅本次：只这一次用，必须选原因（原因 ▸：试磨、排产变更、用户要求、设备原因、质量返修……）；
    • 改为计划：以后这支辊都按它（写进台账、记改动）。
  • 回到计划 撤销这一次的更换。打开辊形 / 打开程序 跳过去看。

中断、续磨、返磨

  • 磨到一半停了（急停、断电、复位），这份作业变成"中断"，在待磨清单置顶。两条路：续磨 ▸（先重新量磨前直径，按剩余余量重算粗磨后再下发），或 结束中断…（按最后一次测量写当前直径，记录标中断）。
  • 不合格的辊：结果横幅、记录页、待磨清单都有 返磨，按同一计划新开作业，置顶。

10自动磨削

方式为 AUTO 时机床区的入口页，下发后自动切过来。这一页不画路径条和通道行，把地方留给加工数据；左栏、右侧竖键、底部横键与其他页一样。

画面

  • 上排三块（与手动磨削页同一个控件）：
    • 位置：第一行是方式 · 通道 · 参考点 · 程序名（只写值，悬停看字段名）；下面 X、X1、Z、U 大字和剩余行程。
    • 主轴与进给：S2 砂轮（r/min · 线速 m/s）、S1 头架（r/min · 工件线速 m/min）、F 拖板进给、X 周期进给；每行右边是倍率，倍率不是 100% 时琥珀色底（红色只留给报警）。
    • 辅助功能：冷却、装夹、支承、测量、机床五组到位灯；开为绿、关为灰、读不到画虚框。
  • 左：工序序列。红底是正在磨的那一道（右端写道次，如 4/10），黄底是下一道，没轮到的写预计时长；下面是本支辊进度和剩余时间。点一道，参数区改看那一道。
  • 中上：曲线。右侧竖键 1–5 选误差曲线、参考曲线、圆度、偏心度、磨削电流；标题右边是公差和辊形误差 RMS。双指缩放、拖动，图角"⟲ 复位视图"回到全貌。
  • 中下：工艺参数。看的那一道（红 / 黄底列头同左边序列）与下一道并排；参数分速度、进给、道次与去除、其他四组，组名竖排在左；变速三项合成一行"±8%/5 转"。参数区高度按这支作业最高的一张固定，开始加工、换道时曲线不跳。横键 参数总表 切到全部工序的总表（行 = 参数，列 = 工序），再按一次回来。
  • 右：三块。轧辊实测直径（大字）、目标、余量和"已去除 %"条；磨削电流条（超上限变红，上限读 machine.json 的 grindingCurrentLimitA）；测头 A / B、对中偏差、砂轮直径、补偿版本与实时补偿量。

运行中改参数

  1. 在参数区点要改的格子，输入新值。格子变蓝加粗，参数区左上写"待下发 n"，竖键 7 / 8 变成 ✕ 放弃改动 / ✓ 下发改动。
  2. 按 ✓ 下发改动。新值写进那一道的 R 参数，NC 在下一道次读取。

已经磨完的工序改不动；正在磨的那一道只能改标了"可在线调整"的参数；还没轮到的随便改。变速这一行在对照表里只读，要改到参数总表里改。

横键

横键作用

磨完

  • NC 发出"循环结束"后，结果横幅盖住本页：标题写"✓ 合格"或"✗ 不合格"（没量到写"没量到，不下结论"），下面是判定依据（项目、实测、允许、结论）。合格 = 辊形误差 ≤ 辊形公差，且圆度等 ≤ 标定里的验收公差。
  • 记录自动收尾，台账当前直径写成磨后实测两端平均（没量到按目标直径）；程序里勾了"打印磨前 / 磨后数据"的自动送默认打印机（磨前数据在下发时打）。

手动磨削页（横键 F1）

12砂轮与标定

左栏 ▦ 砂轮。横键 砂轮 标定 标定审计。改值要管理员权限；改了没存，竖键 7 / 8 是"✕ 放弃改动 / ✓ 保存"。

  • 砂轮：砂轮数据（当前直径、新砂轮直径、宽度、已磨去、最高线速度）与修整参数各配一张简图，下面是修整与更换记录。程序里插"砂轮修整"时照这里的修整参数填。
  • 新砂轮登记：先登标称直径保存，装上后走 换砂轮 ▸。
  • 换砂轮 ▸ 向导 6 步，每步一张图：填新砂轮直径 → 切手动对刀 → 试磨一刀，填预期和实测 → 看反推的砂轮直径误差与修正值 → 接受（或 这一刀不作数）→ 切回原来的对刀方式。放弃换砂轮… 中途退出。
  • 标定：按部件分组（砂轮、金刚笔与修整、测头、基准盘、对刀、验收公差）。标定审计列出每次改动的人和时间。

13记录与报表

左栏 ▤ 记录（或自动页 磨削记录）。

  • 总览：临近报废（剩余可磨量不到两次标准余量）、今日计划变更、不合格待返磨（可直接建返磨）。
  • 磨削记录：竖键 查询… 选起止日期（或今天 / 近 7 天 / 近 30 天）→ ✓ 查询。列表显示辊号、开始时间、辊形、状态与合格；下面是本月支数、合格率、累计时长。
  • 选中一条：12 项指标（磨前 / 磨后直径两端、锥度、辊形误差 RMS、圆度、同轴度、实际凸度、砂轮磨后直径、磨削时长、补偿迭代次数）；竖键 1–4 切换曲线：磨前 / 磨后辊形、误差曲线、圆度、补偿收敛。没量到的项显示"--"（不是 0）。
  • 标记完成…：没自动收尾的记录手动收尾（例如磨完时上位机没开）。
  • 下发参数：看这一次实际下发的快照——调整后的工序参数、套好的辊形点列、核对结果、磨削起点。排查问题时用。
  • 打印（磨后报表）、横键 磨前报表：先出预览，竖键 打印。
  • 日报 月报：本日 / 本月开几支、合格几支、合格率、累计时长。导出 Excel 存成 CSV。

14诊断

左栏 ⚠ 诊断，或点标题行上的报警。

  • 报警：左边报警表，右边选中那条的详情和消除方法。PLC 报警（≥ 500000）按按钮板"故障复位"，NC 报警按"复位"，上位机报警（800000–800999）按竖键 清除报警…。导出故障快照 给售后。
  • 变量监视：实时看 NC / PLC 变量。改动记录：辊形、程序、计划、补偿、配置的每次改动（原值 → 新值、谁、何时）。运行日志。
  • 连接与接口：NC 连接、标签映射版本、可选功能是否启用（例如"NC 侧报废保护：未启用"）。
  • 备份与恢复：竖键 备份 生成一个 zip（配置与数据库）；恢复要停机做，页面上写了步骤。

15调试（制造商）

按 F10 → 调试，要制造商权限。横键 机床配置（machine.json，按分组的表单）、标签映射（tagmap.json，表格：只看缺失 登记 删除这一行… 试读）、系统。改动即校验，不成立存不进去；✓ 保存… 先问一句，原文件自动备份，每项改动进改动记录，重启上位机后生效；恢复上一版… 载入最近一份备份。

可选逻辑名（登记了才启用）

逻辑名作用没登记时
job.grindStartZMm磨削起点 Z 随作业下发；作业页出现"磨削起点 Z"一行，核对要求示教NC 程序自己找端面，作业页不显示这一行

16账号与权限

角色逐级包含：高一级有低一级的全部权限。权限不够的页照样能看，路径条写"只读 · 要××权限"，改动的键和输入格是灰的。

角色能做什么
操作者登记和修改轧辊、下作业、下发、启动 / 暂停、运行中改参数、手动页动作、查记录（PIN 登录）
管理员另外：辊形、工艺程序、标定值与砂轮参数、换砂轮、账号管理
制造商全部，另外：补偿设定、机床配置、标签映射。系统至少保留一个制造商账号

改轧辊计划默认操作者就能改；config/hmi.json 里 "planChangePermission": "administrator" 改成只有管理员能改。

管理账号：点标题行上的名字 → 用户管理：在"新建账号"一行填用户名、按权限分段键选角色，密码留空由本人首次登录时设，按 新建。

17常见问题

现象原因与处理
键是灰的按一下，对话行会说原因：权限不够、自动循环在跑、先选一支辊、缺标签、急停中……
"✓ 确认下发"是灰的核对里有红色"不通过"的项，按一下对话行说是哪一项。常见的见附录 C。
辊形存不进去错误列在预览上方：没填参考轧辊、各段合计和设计长度不等、交界跳变、点表不成立……
换了一支长度不同的辊，辊形被拦中间段是 CVC 或点表，长度差超过 2%。按这支辊重新画一条辊形（参考轧辊填它）。
辊形、程序页变只读自动循环在跑（路径条"只读 · 运行中"），磨完自动解锁；或者权限不够。
机构灯是虚框这个状态位的 PLC 地址没登记，或 NC 断线。到诊断 › 连接与接口、调试 › 标签映射查。
记录没有收尾NC 没发循环结束信号（job.cycleComplete 未登记），或磨完时上位机没开：记录页 标记完成…。
上位机卡住、被关掉正在磨的辊照样磨完。重新开机后检查记录，必要时手动收尾。

C作业核对项

红 = 不通过，拦住下发；橙 = 提示，不拦。

核对项查什么结果
轧辊作废的辊不能下作业红
库条目辊形、程序已停用；或这支辊还没有计划红
磨前直径仍是公称值且没实测（像新辊）；中断后续磨没重新量橙 / 红
磨削量目标直径低于报废直径（给出最多还能磨多少）红
余量分配本次磨削量比精工序余量之和还少，粗磨吸收不了红
辊身长度2% 规则：中间是 CVC / 点表且长度差超过容差红
轧辊类型程序适用类型与辊不符红
材质程序适用材质与辊不符橙
工件线速度头架转速按这支辊直径换算的线速度超出机床范围红
按辊重限速头架转速超出按辊重的上限红
行程辊身长度超出机床行程红
磨削起点NC 要这个数却没示教（红）；沿用上次的值（橙，装夹动过要重新示教）红 / 橙
与计划仅本次没选原因（红）；这一次与计划不同、计划由历史推断（橙）红 / 橙
剩余寿命磨后离报废不到两次标准余量；没登记报废直径橙
工序参数参数超机床能力等，逐条列出红
